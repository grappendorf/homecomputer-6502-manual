BError Messages

An error message begins with a question mark and ends with ERROR. If a program is running, IN and the line number follow:

?SYNTAX ERROR IN 10

In direct mode the line number is missing. The program stops. The variables keep their values, and you can look at them with PRINT. Correct the line and start again with RUN.

BREAK IN 10 is not an error message. Pause, Ctrl+C, or STOP halted the program. CONT resumes it.

In a Program

NEXT WITHOUT FOR

?NEXT WITHOUT FOR ERROR

A NEXT has no matching FOR. The name after NEXT must be the same as the one after FOR, or you can leave it off.

10 NEXT Ino FOR I before it

Write the loop out in full, for example 10 FOR I=1 TO 5 and 20 NEXT I.

SYNTAX

?SYNTAX ERROR

The computer does not understand the line. Often a command is misspelled, a character is missing, or a name contains a BASIC keyword.

10 PRONT "HELLO"PRINT misspelled

The line must read 10 PRINT "HELLO". If the error is in a DATA line, the message points to that line.

RETURN WITHOUT GOSUB

?RETURN WITHOUT GOSUB ERROR

A RETURN is reached even though no GOSUB jumped there.

10 RETURNno GOSUB before it

Call the subroutine with GOSUB. RETURN belongs at its end, not at the start of the program.

OUT OF DATA

?OUT OF DATA ERROR

READ wants another value, but the DATA list is exhausted. The message points to the line containing the READ.

10 READ A,B
20 DATA 1one value short

Add to the list, here 20 DATA 1,2. To read the same list a second time, use RESTORE first.

ILLEGAL QUANTITY

?ILLEGAL QUANTITY ERROR

A number is outside the permitted range. SQR and LOG do not accept negative numbers. CHR$ takes 0 to 255. With POKE, the address runs from 0 to 65535 and the value from 0 to 255. A filename may be 1 to 16 characters long.

PRINT SQR(-1)square root of a negative number

Enter a value within the permitted range. Before taking a square root, check with something like IF X>=0 THEN PRINT SQR(X).

OVERFLOW

?OVERFLOW ERROR

The result is too large. The largest number is about 1.7E+38.

PRINT 1E38*10is beyond that

Work with smaller numbers, or catch large intermediate results before multiplying further.

OUT OF MEMORY

?OUT OF MEMORY ERROR

Memory is insufficient. Usually an array is too large, or strings take up too much space. After switching on, 31423 bytes are free for program and variables.

DIM A(100,100)over 50 000 bytes

Choose a smaller array. You can delete long strings by assigning "" to the variable. CLEAR frees all variable memory; the program stays.

UNDEF'D STATEMENT

?UNDEF'D STATEMENT ERROR

GOTO, GOSUB, or RUN targets a line that does not exist.

10 GOTO 20line 20 is missing

Create the line, or change the number in the jump. LIST shows which lines actually exist.

BAD SUBSCRIPT

?BAD SUBSCRIPT ERROR

An array index is out of range, or the number of indices is wrong. The first index is 0. DIM A(2) provides slots 0, 1, and 2. Without DIM, the index runs from 0 to 10.

10 DIM A(2):PRINT A(3)3 does not exist

Stay within the range, or make the array larger with DIM. An array with two indices must be accessed with two: B(1,2), not B(1).

REDIM'D ARRAY

?REDIM'D ARRAY ERROR

DIM creates an array that already exists in this run. Even the same size counts as a second time.

10 DIM A(2)
20 DIM A(3)A already exists

Leave out the second DIM. RUN and CLEAR forget the arrays; after that, DIM is allowed again.

DIVISION BY ZERO

?DIVISION BY ZERO ERROR

Division by 0 was attempted.

PRINT 1/0

Check the divisor first: IF N<>0 THEN PRINT 1/N.

ILLEGAL DIRECT

?ILLEGAL DIRECT ERROR

INPUT and DEF FN work only in a program, not in direct mode.

INPUT Atyped without a line number

Write 10 INPUT A and start it with RUN.

TYPE MISMATCH

?TYPE MISMATCH ERROR

Number and text are mixed up. A is a number, A$ a string. You may not assign one to the other or combine them in a calculation.

A="HELLO"text into a numeric variable

The string belongs in A$="HELLO". VAL gets a number from a string, STR$ a string from a number.

STRING TOO LONG

?STRING TOO LONG ERROR

A string grows longer than 255 characters. A filename over 16 characters does not fall under this either; it produces ILLEGAL QUANTITY.

10 A$=""
20 FOR I=1 TO 256
30 A$=A$+"X"
40 NEXT I

In line 30 it fails at 256 characters. Let the loop run only to 255, or split the string across several variables.

FORMULA TOO COMPLEX

?FORMULA TOO COMPLEX ERROR

A string expression needs more than three intermediate results at once. BASIC cannot hold that many.

Split the expression. First put two parts into a variable, then the rest:

A$=LEFT$("AB",1)+MID$("CD",2,1)
PRINT A$+RIGHT$("EF",1)

CAN'T CONTINUE

?CAN'T CONTINUE ERROR

CONT cannot resume. Either the program is not stopped at a STOP, at Pause, or at Ctrl+C, or you changed it while it was halted.

CONTright after switching on

Stop with STOP and type CONT without changing a line first. After a change, only RUN helps.

UNDEF'D FUNCTION

?UNDEF'D FUNCTION ERROR

FN calls a function that DEF FN has not defined in this run.

PRINT FNA(1)no DEF FNA

Define it earlier in the program, for example 10 DEF FNA(X)=X*X, and only then call it.

REDO FROM START

?REDO FROM START

INPUT expected a number and received a string. The program does not abort. You enter the whole line again.

10 INPUT A

If you type, say, HELLO at the question mark, the message appears and INPUT asks again. Type a number.

EXTRA IGNORED

?EXTRA IGNORED

INPUT received more values than there are variables. The surplus ones are discarded, and the program continues.

10 INPUT A

If you type 1,2, A stays 1 and the 2 disappears. If you need both, write INPUT A,B.

Disk Drive

These messages come from LOAD, SAVE, DIR, and DELETE. How to connect the disk drive is described in Chapter 6.

NO DISK

?NO DISK ERROR

No drive is connected to the serial port.

LOAD "test"with no disk drive connected

Connect it as described in Chapter 6 and enter the command again.

FILE NOT FOUND

FILE NOT FOUND

The file does not exist on the disk. The program in memory stays as it is. Uppercase and lowercase matter.

LOAD "missing"no missing.prg and no missing.bas

DIR shows the existing names. Load one of those, or save the file first with SAVE.

BAD LOAD

BAD LOAD

A .prg file does not fit into memory. The first two bytes must be the load address $0441, that is 65 and 4, and the file must not be too large. Memory stays empty.

Use a file built the way Chapter 7 describes. Load a BASIC program as .bas, not as .prg.

NO PROGRAM

NO PROGRAM

SAVE finds no program in memory.

NEW
SAVE "empty"nothing to save

Write a program first, then SAVE.

EMPTY FILE

EMPTY FILE

The file exists but contains no program.

LOAD "empty"the file has no lines

Save the program again, or load a different file. DIR shows the size. 0 bytes means empty.
