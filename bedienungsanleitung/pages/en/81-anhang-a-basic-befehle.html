ABASIC Commands

Chapters 3 through 6 introduced you to BASIC step by step. This appendix is meant for looking things up. It lists every command and every function of HomeComputer 6502 BASIC, with its syntax, a short description, and an example. Feel free to try the examples. A mistyped command won't harm the computer. At worst it reports an error, and Appendix B explains the errors.

The appendix has four parts:

  1. Variables and operators: numbers, text, variable names, arrays, arithmetic operators, and comparisons.
  2. Commands: the commands you use to start, view, load, save, and delete programs.
  3. Statements: everything that can appear in a program line, from CLEAR to WAVE.
  4. Functions: math, string, and output functions.

In the syntax notation, italic words stand for something you supply yourself. Anything in [ ] may be left out. … means: it can continue like this.

Variables and Operators

Numbers

BASIC computes with floating-point numbers, that is, numbers with a decimal point. They have about nine significant digits. Instead of a comma you write a period: 3.14. Very large and very small numbers are written by BASIC with E and a power of ten: 1.5E+06 is 1.5 million, 2E-03 is 0.002. The largest number is about 1.7E+38. Anything beyond that reports ?OVERFLOW ERROR.

Variables

A variable is a name for a value. There are three types. The last character of a variable's name tells you which type it is:

TypeExampleholds
floating pointA, X1, PIa number with about 9 significant digits
integerA%, N%a whole number from −32768 to 32767
stringA$, NA$text with 0 to 255 characters

A name begins with a letter; letters and digits may follow. However, BASIC distinguishes only the first two characters. POINTS and PUMP are the same variable PU. No BASIC keyword may appear inside a name: TOTAL contains TO and produces ?SYNTAX ERROR.

A new variable is 0 or empty. RUN, CLEAR, and NEW reset all variables. If you assign a number with a decimal point to an integer variable, the digits after the decimal point are dropped.

Arrays

An array is a series of variables under a single name. The individual slots carry a number in parentheses, the index. It starts at 0. DIM A(20) sets up the slots A(0) through A(20). An array may have several indices: DIM B(3,4). If you use an array without DIM, BASIC creates it with slots 0 through 10. Arrays exist in all three types: A(5), A%(5), A$(5).

Arithmetic Operators

+addition; with strings: concatenation
-subtraction; in front of a number: minus sign
*multiplication
/division
^exponentiation: 2^8 is 256

Comparisons

=equal to
<>not equal to
<less than
>greater than
<=less than or equal to
>=greater than or equal to

A comparison yields −1 if it is true and 0 if not. PRINT 3<5 prints -1. BASIC compares strings character by character according to their codes. "ABC"<"ABD" is true.

Logical Operators

ANDboth conditions are true
ORat least one condition is true
NOTreverses a condition

In fact, the three of them work on the individual bits of an integer from −32768 to 32767. That's why PRINT 12 AND 10 also works and yields 8. With comparisons (−1 and 0) they behave like "and", "or", and "not".

Order of Evaluation

As in mathematics, multiplication and division come before addition and subtraction. The full order, from highest to lowest:

^exponentiation
-minus sign in front of a number
* /multiplication, division
+ -addition, subtraction
= <> < > <= >=comparisons
NOT
AND
OR

Parentheses change the order: 2+3*4 is 14, (2+3)*4 is 20.

Commands

You usually type these commands without a line number. The computer then executes them immediately. This is called direct mode.

CONT

CONT

Resumes a program you stopped with Pause or Ctrl+C, or that halted at a STOP. It continues at exactly the point where it stopped. While it's paused you may view and change variables, for example with PRINT A. But if you change the program itself, CONT no longer works, and you get ?CAN'T CONTINUE ERROR.

DELETE

DELETE "name"

Deletes a file on the disk. First the computer asks DELETE? (Y/N). Only Y deletes the file; DELETED then appears. Any other key leaves it alone. If the file is missing, you see FILE NOT FOUND. Chapter 6 explains how to connect the disk.

DELETE "test"deletes the file test

DIR

DIR

Shows the directory of the disk: for each file, the size in bytes and the name. Three files appear on the display, then MORE - PRESS A KEY, and the LED lights up. Press a key to continue. At the end END OF DIRECTORY appears. Pause aborts the listing.

LIST

LIST [from] [-[to]]

Shows the program in memory. Without a number the whole program is listed; with numbers, only part of it. On the display LIST stops after three lines, shows MORE - PRESS A KEY, and lights the LED. A key shows the next lines. Pause aborts. On the serial terminal the listing runs through without stopping.

LISTthe whole program
LIST 100only line 100
LIST 100-200lines 100 through 200
LIST -200from the beginning through line 200
LIST 100-from line 100 to the end

LOAD

LOAD "name"

Loads a program from the disk. The old program in memory is replaced. While loading, a bar shows the progress; at the end LOADED appears. The name has at most 16 characters. Without an extension the computer first looks for name.prg, then name.bas. A .prg file contains machine language (see Chapter 7); a .bas file contains a BASIC program as text. Case matters in the name, because the files live on the PC.

If the file is missing, the old program stays in memory and you get FILE NOT FOUND. With no disk connected, the computer reports NO DISK.

LOAD "galgen"loads galgen.bas

NEW

NEW

Erases the program and all variables. Save a program you still need first with SAVE. A deleted program cannot be brought back.

RUN

RUN [line]

Starts the program in memory. Before that, RUN sets all variables to 0 or empty. Without a number the program begins at the lowest line number; with a number, at that line.

RUNstarts at the beginning
RUN 500starts at line 500

SAVE

SAVE "name"

Saves the program to the disk. The file is plain text, one line per program line, exactly as LIST shows it. That's why you can also read and edit it on the PC. The bar shows the progress; at the end SAVED appears. A file with the same name is overwritten. If there is no program in memory, you see NO PROGRAM.

SAVE "guess"saves as guess.bas

Statements

The following statements usually appear in program lines. Most of them also work in direct mode. Separate several statements on one line with a colon.

CLEAR

CLEAR

Erases all variables and arrays. The program is kept. RUN does this automatically.

CLS

CLS [#device]

Clears the display and puts the cursor at the top left. #1 always means the LCD, #2 the serial terminal (see Chapter 6). Without a specification, the device you are currently working on applies. The same goes for LOCATE, CURSOR, PRINT, and INPUT.

CURSOR

CURSOR [#device] ON | OFF
CURSOR [#device] BLINK ON | OFF

CURSOR ON and CURSOR OFF turn the underscore cursor on and off. CURSOR BLINK ON additionally makes the character at the cursor position blink; CURSOR BLINK OFF stops that. The underscore and the blinking are independent of each other. In games the cursor is usually turned off so it doesn't jump around the display. After the program, turn it back on with CURSOR ON.

DATA

DATA value, value, …

Stores a list of values in the program. READ reads them in order. The values can be numbers or text. Text needs quotation marks only if it contains a comma, a colon, or leading or trailing spaces. DATA lines may appear anywhere in the program. The computer skips them when running it.

10 DATA 12,14.5,"HELLO, YOU",MOUSE

DEF FN

DEF FNname(variable) = expression

Defines your own math function. The name is a variable name of one or two characters, preceded by FN. The variable in parentheses is a placeholder. On a call, BASIC substitutes the number you pass in there. A function takes exactly one number and returns a number. DEF FN works only in a program, not in direct mode.

10 DEF FNQ(X)=X*X
20 PRINT FNQ(7)

prints 49.

DIM

DIM name(size[, size …]) [, …]

Sets up an array. The size is the highest index. DIM may be executed only once per array. A second time reports ?REDIM'D ARRAY ERROR. An index outside the size gives ?BAD SUBSCRIPT ERROR. Separate several arrays with commas.

DIM A(50)51 numbers, A(0) through A(50)
DIM W$(20),F%(3,3)21 strings and 4×4 integers

DISPLAY

DISPLAY ON | OFF

Turns the display dark and back on. The text stays stored and is instantly back after DISPLAY ON. This lets you build up a display in the background and then show it all at once.

EFFECT

EFFECT number

Plays a built-in sound effect. It runs on voice 3 and in the background, so the program continues immediately. Voices 1 and 2 keep playing undisturbed.

EFFECT 1shot
EFFECT 2explosion
EFFECT 3laser
EFFECT 4jump
EFFECT 5coin
EFFECT 6extra
EFFECT 7error
EFFECT 8siren
EFFECT 9falling bomb

END

END

Ends the program without a message. END doesn't have to be at the end. It's mostly needed so a program doesn't run into the subroutines that follow it.

ENVELOPE

ENVELOPE instrument, attack, decay, sustain, release

Sets the envelope of an instrument, that is, how a note gets louder and quieter. Instruments 0 through 7, each level 0 through 15. Attack is the swell, decay the fall to the hold level sustain, release the fade-out at the end. The next note with this instrument uses the new envelope. The waveform stays unchanged.

ENVELOPE 4,0,9,0,0instrument 4 becomes a short pluck

FOR … TO … STEP

FOR variable = start TO end [STEP step]

Begins a counting loop. The variable first gets the start value. Then the statements up to the matching NEXT run. There the step is added. If the variable hasn't yet passed the end, BASIC jumps back to just after the FOR. Without STEP the step is 1. With a negative step the loop counts backwards. The loop always runs at least once.

FOR I=1 TO 101, 2, 3 … 10
FOR I=0 TO 1 STEP 0.250, 0.25, 0.5, 0.75, 1
FOR I=10 TO 1 STEP -310, 7, 4, 1

GOSUB

GOSUB line

Jumps to a subroutine that begins at the given line. When BASIC hits a RETURN there, it continues just after the GOSUB. Subroutines may themselves use GOSUB again.

10 GOSUB 100:GOSUB 100:END
100 PRINT "HELLO":RETURN

GOTO

GOTO line

Jumps to a line and continues there. If the line doesn't exist, BASIC reports ?UNDEF'D STATEMENT ERROR. Instead of GOTO you may also write GO TO. In direct mode GOTO starts the program at that line without clearing the variables.

IF … THEN

IF condition THEN statements
IF condition THEN line
IF condition GOTO line

Tests a condition. If it is true, BASIC executes the statements after THEN or jumps to the given line. If it is not true, execution continues on the next line. So all statements after THEN on the same line belong to the condition. Any number counts as a condition: 0 means "false", anything else "true".

IF A>10 THEN PRINT "TOO BIG":A=10
IF K=27 THEN 900jumps to line 900
IF A$="J" AND P>0 GOTO 50

INPUT

INPUT [#device,] ["text";] variable, …

Waits for input from the keyboard. The text appears as a prompt, followed by a question mark. What you type up to Return ends up in the variable. With several variables, separate the inputs with commas. If you type too few, the computer asks for the rest with ??. If you type letters where a number is expected, you get ?REDO FROM START, and you enter everything again. INPUT works only in a program.

INPUT "YOUR NAME";N$asks for a text
INPUT X,Ytwo numbers, for example 3,4
INPUT #1,A$always reads from the keyboard

LED

LED ON | OFF

Turns the LED at the top right on or off. After power-on it lights up by itself for one second. The first LED statement takes it over completely after that.

LET

[LET] variable = expression

Gives a variable a value. You may leave out the word LET; LET A=5 and A=5 do the same. Numbers and text must not be mixed. A="X" gives ?TYPE MISMATCH ERROR.

A=A+1increments A by one
N$="OTTO"

LOCATE

LOCATE [#device,] row, column

Positions the cursor. The next PRINT writes at that spot. On the LCD the row runs from 0 to 3 and the column from 0 to 39. On the serial terminal the limits of TERM apply.

LOCATE 3,35:PRINT "END";writes at the bottom right

NEXT

NEXT [variable] [, variable …]

Closes a FOR loop. You may leave out the variable; the NEXT then belongs to the innermost loop. NEXT J,I closes two nested loops at once. If the variable matches no FOR, BASIC reports ?NEXT WITHOUT FOR ERROR.

ON

ON expression GOTO line, line, …
ON expression GOSUB line, line, …

A dispatcher. If the expression is 1, BASIC jumps to the first line of the list; if it's 2, to the second, and so on. Digits after the decimal point are dropped. If the value is 0 or larger than the list is long, execution simply continues with the next statement.

ON W GOSUB 100,200,300W=2 calls line 200

PLAY

PLAY slot [ON | OFF] [, …]

Plays a melody you previously stored with TUNE. Slot 1 through 3 is also the voice. The melody runs in the background; the program continues immediately. With ON it repeats endlessly. PLAY slot OFF stops one voice, PLAY 0 all three.

PLAY 1play slot 1 once
PLAY 1 ON,2repeat slot 1, slot 2 once
PLAY 2 OFFstop only voice 2
PLAY 0stop all of them

POKE

POKE address, value

Writes a byte into memory. The address runs from 0 to 65535, the value from 0 to 255. Careful: a POKE to the wrong place can confuse BASIC. Then only a reset helps. The computer won't be damaged, but the program in memory is usually lost afterwards. Appendix C shows which addresses are there for what.

PRINT

PRINT [#device,] [expression] [; | ,] …

Writes numbers and text to the display. Instead of PRINT you may type ?. What stands between the expressions determines the spacing:

;continues printing right after
,jumps to the next column 0, 10, 20, or 30
nothing at the endgoes to the next line after printing

Numbers get a leading space if they are positive, and always a trailing one. A line longer than 40 characters continues on the next display line. TAB and SPC help with alignment (see Functions).

PRINT "SUM:";A+B
PRINT "A","B","C"three columns
PRINT #2,"TO THE PC"writes to the serial terminal

QUIT

QUIT

Ends the serial BASIC terminal (Chapter 6). The connection goes back to the monitor, and BASIC uses keyboard and LCD again. The program in memory is kept. serial-basic.sh sends QUIT by itself when you leave the terminal. Without a serial terminal, QUIT is a ?SYNTAX ERROR.

READ

READ variable, …

Reads the next value from the DATA lines into a variable. Each READ advances in the list. When all values have been read, BASIC reports ?OUT OF DATA ERROR. The variable's type must match the value: text cannot be read into a numeric variable.

10 FOR I=1 TO 3:READ N$:PRINT N$:NEXT
20 DATA ANNA,BERT,CARLA

REM

REM text

A remark for humans. BASIC skips everything after REM up to the end of the line, including colons and statements. Remarks cost memory, but they make a program much easier to understand.

10 REM *** HANGMAN ***

RESTORE

RESTORE

Resets reading of the DATA lines. The next READ reads the first value in the program again.

RETURN

RETURN

Ends a subroutine. BASIC continues just after the GOSUB that called it. A RETURN without a GOSUB gives ?RETURN WITHOUT GOSUB ERROR. That often happens when the END in front of the subroutines is missing.

SLEEP

SLEEP seconds

Waits for a while. Fractions work too: SLEEP 0.1 waits a tenth of a second. Melodies and effects keep playing while it waits. Pause cancels the wait.

SOUND

SOUND voice, frequency, duration [, instrument]

Plays a note on voice 1, 2, or 3. The note runs in the background; the program continues immediately. The frequency is the number the SID chip expects, from 0 to 65535. It is about 16.78 times the frequency in hertz. Middle C (261.6 Hz) is 4389. The duration counts in sixteenths, 1 to 255, and depends on TEMPO. The instrument (0 to 7) selects waveform and envelope. Without an instrument, the voice keeps its timbre. The frequencies of a whole scale are in Chapter 5.

SOUND 1,4389,8,1a C on the piano, one second long

STOP

STOP

Halts the program and reports BREAK IN with the line number, just like the Pause key. With CONT it continues. STOP helps with debugging: you halt the program at a particular point and examine the variables.

SYS

SYS address

Starts a machine-language program at the address (0 to 65535). If it ends with the RTS instruction, the BASIC program continues. More on that in Chapter 7.

TEMPO

TEMPO n

Sets how many sixteenths pass per second, from 1 to 50. After power-on it is 8. The tempo applies to the duration in SOUND and to the note lengths in TUNE, not to EFFECT.

TERM

TERM [columns [, rows]]

Specifies the size of the serial terminal. After startup that's 80 columns and 24 rows. PRINT, LOCATE, and the wrapping of long lines orient themselves on it. Without numbers, TERM prints the current size. The terminal window on the PC must be at least that big.

TUNE

TUNE slot, "notes"

Stores a melody in slot 1, 2, or 3. PLAY then plays it. The notes are a text of at most 47 characters. Spaces are skipped, upper or lower case doesn't matter.

C D E F G A Bnotes; B is the German H
C#a note raised by one semitone
C5note with octave 0 through 7
O3octave for the following notes
L8length in sixteenths, 1 through 8
I1instrument 0 through 7
R2rest, here two sixteenths long

At the start, octave 4, length 4, and instrument 0 apply. A setting stays in effect until a new one comes.

TUNE 1,"L4CDEFL8GG"beginning of "Alle meine Entchen"

VOL

VOL level

Sets the overall volume of all three voices, from 0 (silent) to 15 (loud). After power-on it is 15. How loud the speaker is overall is controlled by the rotary knob on the device.

WAIT

WAIT address, mask [, invert]

Waits until certain bits are set at a memory address. BASIC reads the byte over and over, combines it with invert by XOR, then with mask by AND. As soon as the result is not 0, it continues. This is a statement for advanced users that works with the hardware. If it waits forever, Pause helps.

WAVE

WAVE voice, shape [, pulse width]

Changes the waveform of a voice immediately, even in the middle of a note. Shape 0 is triangle, 1 sawtooth, 2 pulse, 3 noise. The pulse width (0 to 4095) is audible only with shape 2. 2048 gives an even square wave. The next note with an instrument number restores the instrument's waveform.

Functions

A function returns a value. That's why it never stands alone but always inside an expression, for example after PRINT or to the right of the equals sign. The values it computes with go in parentheses.

Math Functions

ABS(x)Absolute value: x without its sign. ABS(-7) is 7.
ATN(x)Arctangent of x, in radians.
COS(x)Cosine. x is in radians; a full circle is 2π, about 6.283.
EXP(x)e (2.71828…) raised to x.
FNname(x)Your own function, defined with DEF FN.
INT(x)Largest whole number not greater than x. INT(3.7) is 3, INT(-3.7) is −4.
LOG(x)Natural logarithm. x must be greater than 0. You get the base-10 logarithm with LOG(x)/LOG(10).
RND(x)Random number between 0 and 1 (not including 1). With a positive x you get the next number. A negative x sets a start value; x=0 repeats the last number. A whole random number from 1 to 6: INT(RND(1)*6)+1.
SGN(x)Sign: −1 if x is negative, 0 if it is 0, otherwise 1.
SIN(x)Sine, x in radians.
SQR(x)Square root. x must not be negative.
TAN(x)Tangent, x in radians.
USR(x)Calls a machine-language program and passes it x. The start address is in memory locations 11 (low byte) and 12 (high byte). See Chapter 7.

String Functions

ASC(t$)Character code of the first character. ASC("A") is 65. The codes are in Appendix D.
CHR$(n)The character with code n (0 to 255). CHR$(65) is "A".
LEFT$(t$,n)The first n characters. LEFT$("COMPUTER",4) is "COMP".
LEN(t$)Number of characters. LEN("OTTO") is 4.
MID$(t$,a[,n])n characters starting with the a-th character. The first character is number 1. Without n it goes to the end. MID$("COMPUTER",5,3) is "UTE".
RIGHT$(t$,n)The last n characters. RIGHT$("COMPUTER",4) is "UTER".
STR$(x)The number as text, exactly the way PRINT would write it. Positive numbers begin with a space: STR$(42) is " 42".
VAL(t$)The number at the beginning of the text. VAL("12.5KG") is 12.5. If the text doesn't begin with a number, the result is 0.

Other Functions

FRE(0)How many bytes of memory are still free. The number in parentheses doesn't matter.
KEY(0)The code of the key currently pressed, or 0. KEY doesn't wait. The arrow keys return 17 through 20; the remaining codes are in Chapter 4 and Appendix E.
PEEK(a)The byte at memory address a (0 to 65535), a number from 0 to 255.
POS(0)The column the cursor is currently in. The first column is 0.

Output Functions

These two work only within PRINT.

SPC(n)Prints n spaces.
TAB(n)Advances to column n. If the cursor is already further right, nothing happens.
PRINT "NAME";TAB(20);"POINTS"POINTS stands in column 20

Not in this BASIC

If you know BASIC from the C64, you may miss a few commands. There is no GET; use KEY(0) instead. CLR is called CLEAR here. OPEN, CLOSE, CMD, and VERIFY are also missing. TI and ST are just ordinary variables here with no special meaning. You reach the disk through LOAD, SAVE, DIR, and DELETE.
