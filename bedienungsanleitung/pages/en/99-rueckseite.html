A Computer
You Build Yourself

The HomeComputer 6502 is a home-built computer with the processor of the early eighties. Display, keyboard, sound chip and battery are built in. After switching it on, Microsoft BASIC is waiting for you.

This manual shows you how to set it up, write programs, produce sounds and talk to the processor directly. It takes you from the first keypress down to the individual byte.

Processor
MOS 6502, 1 MHz
Memory
32 KB RAM, 32 KB ROM
Display
LCD, 4 × 40 characters
Sound
SID 8580
Language
Microsoft BASIC V1.1
