DCharacter Set

CHR$(n) displays the character with code n, and ASC returns the code. n ranges from 0 to 255. The code is row plus column: row 64, column 1 is 65, hexadecimal $41, the character A.

Code 8 deletes the character in front of the cursor. Code 13 moves the cursor to the start of the line, code 10 down one line. Together, both make a new line. The remaining empty cells display nothing.
