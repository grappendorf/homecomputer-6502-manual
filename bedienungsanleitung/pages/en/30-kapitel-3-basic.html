So far you have been giving the computer individual commands, and it executed them immediately. In this chapter you will write your first programs. A program is a list of commands that the computer remembers and then works through in order, as many times as you like.

The language for this is called BASIC. The HomeComputer 6502 has Microsoft BASIC version 1.1 built in permanently. It is ready to use as soon as you switch the computer on.

Your First Program

Type in the following two lines and press Return after each line:

10 PRINT "HELLO"
20 GOTO 10

This time nothing happens after Return. That is exactly right. Because the lines begin with a number, the computer does not execute them, but stores them instead. The number at the beginning is the line number. It determines the order in which the lines appear in the program. Numbers from 0 to 63999 are allowed.

Now start the program with the command RUN:

RUN

Line 10 writes HELLO on the display. Line 20 says: “Continue at line 10.” The computer jumps back, writes HELLO again, jumps back again, and so on, without end. This is called an infinite loop.

Stopping a Program

Press Pause or Ctrl + C. The program stops, and the computer reports which line it was in:

With CONT (short for continue) the program resumes at the same spot. With RUN it starts again from the beginning.

Note

When a program has finished or was stopped, the computer does not print a message such as READY. The cursor simply sits on the next line, and you can keep typing.

Upper or Lower Case?

The keyboard types lowercase letters. You get capital letters while you hold down Shift. For longer texts, press Caps Lock once briefly: then all letters come out in capitals until you press Caps Lock again. If you hold Shift while Caps Lock is on, you get a lowercase letter. After switching the computer on, Caps Lock is always off.

For BASIC this is no problem. You may type commands and variable names in lowercase. When storing them, the computer converts them to capitals, and that is how LIST shows them too. Only text between quotation marks stays exactly as you typed it. print "Hello" becomes PRINT "HELLO" in the program.

The listings in this manual appear the way LIST shows them: commands in capitals, and text usually in capitals as well. You type such texts with Shift held down or with Caps Lock, or you write them in lowercase – whatever you prefer. In the LCD boxes, your input is shown in lowercase, just as it appears on the display.

Instead of PRINT you can also simply write ?.

Viewing and Changing Programs

The command LIST shows the program currently in memory:

LIST
10 PRINT "HELLO"
20 GOTO 10

With longer programs you can also view just a portion:

Inputshows

LIST 30-from line 30 to the end
LIST -30from the beginning to line 30
LIST 100-200lines 100 through 200

The display has only four lines. If the program is longer, LIST stops after three lines and prints MORE - PRESS A KEY. The LED in the top right corner lights up. Press any key to continue. With Pause or Ctrl + C you cancel.

Replacing, Deleting, and Inserting Lines

  • Replace: Type a line again with the same number. The old line is overwritten.
  • Delete: Type just the line number and press Return.
  • Insert: Pick a number that lies between two existing ones. 15 PRINT "WORLD" becomes a new line between 10 and 20.

That is why programs are numbered in steps of ten: 10, 20, 30. This leaves room for lines you think of later.

Recalling a Line

You do not have to retype an entire line to change it. Press ↑ on an empty input line. The computer recalls the last program line onto the display. Each further ↑ recalls the line before it, ↓ the line after it. If you first type a line number and then press ↑, it recalls exactly that line.

With ← and → you move the cursor within the line. The backspace key deletes the character before the cursor, Del the character under the cursor. Home and End jump to the beginning and the end. Esc discards the entire line. With Return you accept the changed line. If you change the line number in the process, a copy is created under the new number. The old line remains.

A line can be up to 120 characters long. On the display it wraps to the next line after 40 characters.

Starting Over

NEW deletes the entire program and all variables. There is no confirmation prompt. How to save a program to diskette beforehand is described in Chapter 6.

Several Commands on One Line

Several commands fit on one line, separated by a colon. With REM (short for remark) you write a comment. The computer ignores everything after REM, including a colon.

10 REM MY SECOND PROGRAM
20 PRINT "HELLO":PRINT "WORLD"

Variables

A variable is a name under which the computer remembers a value. You assign it a value with the equals sign:

10 A=5
20 B=A*2
30 PRINT A;B

Here the equals sign does not mean “is equal to” but “gets the value”. That is why A=A+1 also makes sense: A gets the old value of A plus one. In the old days you wrote LET A=A+1 for this. That still works, but the LET can be left out.

Three Kinds of Variables

ExampleholdsRange

Text always stands between quotation marks: N$="ANNA". You join two texts with +: PRINT "SNOW"+"MAN" prints SNOWMAN. If you assign a number with a decimal point to an integer variable, everything after the decimal point is dropped: after A%=7.9, A% equals 7.

A variable you have not yet assigned anything is 0 or empty. RUN and NEW reset all variables to 0 or empty.

Good Names

A name begins with a letter. Letters and digits may follow. However, the computer distinguishes names only by their first two characters. To it, NAME$ and NAP$ are the same variable NA$:

NAME$="ANNA":NAP$="X":PRINT NAME$
X

Also, a name must not contain a BASIC command. TOTAL contains TO, FORM contains FOR. Both lead to ?SYNTAX ERROR. The safest choice is short names of one or two characters.

Output with PRINT

PRINT can output several things at once. What stands between them determines the spacing:

  • A semicolon ; continues printing right after.
  • A comma , jumps to the next column. The columns are 10 characters wide.
  • If a ; or , stands at the end, the cursor stays on the line. The next PRINT continues there.

PRINT puts a space in front of every number; for negative numbers the minus sign goes there. A space also follows every number. That is why numbers never sit directly next to each other.

Loops with FOR … NEXT

With GOTO you have already built a loop, although one without an end. If something should happen exactly five times, use FOR and NEXT:

10 FOR I=1 TO 5
20 PRINT I;
30 NEXT I
40 PRINT "DONE"

FOR sets the variable I to 1. Everything up to NEXT is executed. NEXT I increases I by one and jumps back as long as I is not greater than 5. After that, execution continues with the line after NEXT.

Different Steps

With STEP you determine by how much the variable increases each time. A negative step counts backwards:

FOR I=0 TO 20 STEP 5:PRINT I;:NEXT
 0  5  10  15  20
FOR I=10 TO 0 STEP -5:PRINT I;:NEXT
 10  5  0

As you can see, the name after NEXT may also be left out. Then NEXT belongs to the loop that was started last.

Note

A FOR loop always runs at least once. FOR I=5 TO 1 executes the body once with I=5, even though 5 is already greater than 1.

Loops Inside Loops

Loops can be nested. The inner loop must end before the outer one:

10 FOR I=1 TO 3
20 FOR J=1 TO 3
30 PRINT I*J;
40 NEXT J
50 PRINT
60 NEXT I

The plain PRINT in line 50 only ends the line on the display.

Input with INPUT

So far everything was already in the program. With INPUT the program asks you while it runs:

10 INPUT "YOUR NAME";N$
20 PRINT "HELLO ";N$

INPUT prints the text between the quotation marks, appends a question mark, and waits. What you type ends up in the variable after Return. The text and the semicolon may be omitted. Then only the question mark appears.

An INPUT can also ask for several values at once. Separate them with a comma as you type. If you enter too few, the computer asks for the rest with ??:

10 INPUT "TWO NUMBERS";A,B
20 PRINT "SUM:";A+B

If the program expects a number and you type letters, the computer answers with ?REDO FROM START and asks again. The program then continues normally.

Note

INPUT works only in a program. Typed in directly, the computer reports ?ILLEGAL DIRECT ERROR.

Decisions with IF … THEN

A program only becomes truly useful when it reacts to input. For that there are IF and THEN:

10 INPUT "HOW OLD ARE YOU";A
20 IF A<18 THEN PRINT "NOT AN ADULT YET"
30 IF A>=18 THEN PRINT "AN ADULT"

If the condition after IF is true, the computer executes what follows THEN. If it is false, it skips the entire rest of the line, including everything after a colon. You can take advantage of that:

20 IF A<18 THEN PRINT "TOO YOUNG":GOTO 10

Here the program jumps back to line 10 only if A is less than 18.

Text can be compared the same way: IF A$="Y" THEN …. With < and > the order in the alphabet applies; "ABC" is less than "ABD".

You combine several conditions with AND (both must be true) and OR (one must be true). NOT reverses a condition:

IF X>1 AND X<5 THEN PRINT "IN BETWEEN"

THEN with a Line Number

If only a line number follows THEN, the computer jumps there. IF A=0 THEN 100 is the same as IF A=0 THEN GOTO 100 or IF A=0 GOTO 100.

For the Curious

To the computer, a comparison is a calculation. True yields −1, false yields 0. Try PRINT 5>3, 3>5. IF only checks whether the value is 0. That is why IF 7 THEN … executes the command and IF 0 THEN … does not.

A Guessing Game

Now you have everything together for a real game. The computer thinks of a number between 1 and 100, and you guess:

10 REM GUESSING GAME
20 Z=INT(RND(1)*100)+1
30 V=0
40 PRINT "I AM THINKING OF A NUMBER FROM 1 TO 100."
50 INPUT "YOUR GUESS";T
60 V=V+1
70 IF T<Z THEN PRINT "TOO SMALL.":GOTO 50
80 IF T>Z THEN PRINT "TOO BIG.":GOTO 50
90 PRINT "CORRECT! YOU NEEDED";V;"GUESSES."
100 INPUT "AGAIN (Y/N)";A$
110 IF A$="Y" OR A$="y" THEN 20
120 END

You can also find the program in the firmware project as examples/ratespiel.bas. If the disk drive from Chapter 6 is connected, load it with LOAD "ratespiel".

Here is how the program works:

  • Line 20 generates the secret number Z. RND(1) returns a random number between 0 and 1. Multiplied by 100 and rounded down to a whole number with INT, that gives 0 to 99. Plus one: 1 to 100.
  • Line 30 sets the guess counter to 0.
  • Lines 50 and 60 ask for your guess and count along.
  • Lines 70 and 80 compare your guess with Z. If it is off, you get a hint, and the program asks again at line 50.
  • Line 90 is reached only when the guess was neither too small nor too large.
  • Lines 100 and 110 start a new round on request. Because the keyboard types lowercase, line 110 checks for "Y" and for "y". END ends the program.

The texts in the program use only simple characters. This way the text looks the same on every display and every terminal.

Note

After switching on, RND(1) always returns the same sequence of random numbers. The first round therefore always begins with the same number. Chapter 4 shows how to change that.

Error Messages

When the computer does not understand something, it reports an error. The message begins with a question mark. If the error happens in a program, the line number follows:

10 PRINT "A"
20 PRUNT "B"

Don’t worry: an error cannot harm the computer. Recall the line with ↑, correct it, and start the program again. The messages you are most likely to encounter in this chapter:
