DZeichensatz

CHR$(n) zeigt das Zeichen mit dem Code n, ASC liefert den Code. n geht von 0 bis 255. Der Code ist Zeile plus Spalte: Zeile 64, Spalte 1 ist 65, hexadezimal $41, das Zeichen A.

Code 8 löscht das Zeichen vor dem Cursor. Code 13 setzt den Cursor an den Zeilenanfang, Code 10 eine Zeile tiefer. Beides zusammen ist eine neue Zeile. Die übrigen leeren Felder zeigen nichts.
