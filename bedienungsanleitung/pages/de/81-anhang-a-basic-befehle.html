ABASIC-Befehle

Die Kapitel 3 bis 6 haben Ihnen BASIC Schritt für Schritt gezeigt. Dieser Anhang ist zum Nachschlagen gedacht. Hier steht jeder Befehl und jede Funktion des HomeComputer-6502-BASIC, mit Schreibweise, kurzer Beschreibung und Beispiel. Probieren Sie die Beispiele ruhig aus. Ein falsch getippter Befehl schadet dem Computer nicht. Schlimmstenfalls meldet er einen Fehler, und die Fehler erklärt Anhang B.

Der Anhang hat vier Teile:

  1. Variablen und Operatoren: Zahlen, Texte, Variablennamen, Felder, Rechenzeichen und Vergleiche.
  2. Kommandos: Befehle, mit denen Sie Programme starten, ansehen, laden, speichern und löschen.
  3. Befehle: alles, was in einer Programmzeile stehen kann, von CLEAR bis WAVE.
  4. Funktionen: Rechen-, Text- und Ausgabefunktionen.

In der Schreibweise stehen kursive Wörter für etwas, das Sie selbst einsetzen. Was in [ ] steht, dürfen Sie weglassen. … heißt: So kann es weitergehen.

Variablen und Operatoren

Zahlen

BASIC rechnet mit Gleitkommazahlen, also Zahlen mit Komma. Sie haben etwa neun gültige Stellen. Statt des Kommas schreiben Sie einen Punkt: 3.14. Sehr große und sehr kleine Zahlen schreibt BASIC mit E und einer Zehnerpotenz: 1.5E+06 ist 1,5 Millionen, 2E-03 ist 0,002. Die größte Zahl ist etwa 1.7E+38. Was darüber hinausgeht, meldet ?OVERFLOW ERROR.

Variablen

Eine Variable ist ein Name für einen Wert. Es gibt drei Arten. Welche Art eine Variable ist, zeigt das letzte Zeichen ihres Namens:

ArtBeispielenthält
GleitkommaA, X1, PIZahl mit etwa 9 gültigen Stellen
ganze ZahlA%, N%ganze Zahl von −32768 bis 32767
ZeichenketteA$, NA$Text mit 0 bis 255 Zeichen

Ein Name beginnt mit einem Buchstaben, danach dürfen Buchstaben und Ziffern folgen. BASIC unterscheidet aber nur die ersten zwei Zeichen. PUNKTE und PUMPE sind dieselbe Variable PU. In einem Namen darf kein BASIC-Wort stecken: TOTAL enthält TO und ergibt ?SYNTAX ERROR.

Eine neue Variable ist 0 oder leer. RUN, CLEAR und NEW setzen alle Variablen wieder zurück. Geben Sie einer ganzzahligen Variable eine Zahl mit Komma, fallen die Nachkommastellen weg.

Felder

Ein Feld ist eine Reihe von Variablen unter einem Namen. Die einzelnen Plätze tragen eine Nummer in Klammern, den Index. Er beginnt bei 0. DIM A(20) legt die Plätze A(0) bis A(20) an. Ein Feld darf mehrere Indizes haben: DIM B(3,4). Benutzen Sie ein Feld ohne DIM, legt BASIC es mit den Plätzen 0 bis 10 an. Felder gibt es von allen drei Arten: A(5), A%(5), A$(5).

Rechenzeichen

+Addition, bei Zeichenketten: aneinanderhängen
-Subtraktion, vor einer Zahl: Minuszeichen
*Multiplikation
/Division
^Potenz: 2^8 ist 256

Vergleiche

=gleich
<>ungleich
<kleiner als
>größer als
<=kleiner oder gleich
>=größer oder gleich

Ein Vergleich ergibt −1, wenn er stimmt, und 0, wenn nicht. PRINT 3<5 schreibt -1. Zeichenketten vergleicht BASIC Zeichen für Zeichen nach ihrem Code. "ABC"<"ABD" stimmt.

Logische Operatoren

ANDbeide Bedingungen stimmen
ORmindestens eine Bedingung stimmt
NOTkehrt eine Bedingung um

Eigentlich arbeiten die drei mit den einzelnen Bits einer ganzen Zahl von −32768 bis 32767. Deshalb geht auch PRINT 12 AND 10 und ergibt 8. Mit Vergleichen (−1 und 0) verhalten sie sich wie „und“, „oder“ und „nicht“.

Reihenfolge

Wie in der Mathematik gilt Punkt vor Strich. Die ganze Reihenfolge, von oben nach unten:

^Potenz
-Minuszeichen vor einer Zahl
* /Multiplikation, Division
+ -Addition, Subtraktion
= <> < > <= >=Vergleiche
NOT
AND
OR

Klammern ändern die Reihenfolge: 2+3*4 ist 14, (2+3)*4 ist 20.

Kommandos

Diese Befehle tippen Sie meist ohne Zeilennummer ein. Dann führt der Computer sie sofort aus. Man nennt das den Direktmodus.

CONT

CONT

Setzt ein Programm fort, das Sie mit Pause oder Strg+C angehalten haben oder das bei STOP stehen geblieben ist. Es läuft genau an der Stelle weiter, an der es aufgehört hat. In der Pause dürfen Sie Variablen ansehen und ändern, etwa mit PRINT A. Ändern Sie aber das Programm selbst, geht CONT nicht mehr, und es kommt ?CAN'T CONTINUE ERROR.

DELETE

DELETE "Name"

Löscht eine Datei auf der Diskette. Vorher fragt der Computer DELETE? (Y/N). Nur Y löscht die Datei, danach steht DELETED. Jede andere Taste lässt sie stehen. Fehlt die Datei, steht FILE NOT FOUND. Wie die Diskette angeschlossen wird, erklärt Kapitel 6.

DELETE "test"löscht die Datei test

DIR

DIR

Zeigt das Verzeichnis der Diskette: für jede Datei die Größe in Bytes und den Namen. Auf der Anzeige erscheinen drei Dateien, dann MORE - PRESS A KEY, und die LED leuchtet. Mit einer Taste geht es weiter. Am Ende steht END OF DIRECTORY. Pause bricht die Liste ab.

LIST

LIST [von] [-[bis]]

Zeigt das Programm im Speicher. Ohne Zahl kommt das ganze Programm, mit Zahlen nur ein Teil. Auf der Anzeige hält LIST nach drei Zeilen an, zeigt MORE - PRESS A KEY und lässt die LED leuchten. Eine Taste zeigt die nächsten Zeilen. Pause bricht ab. Auf dem seriellen Terminal läuft die Liste ohne Halt durch.

LISTdas ganze Programm
LIST 100nur Zeile 100
LIST 100-200Zeilen 100 bis 200
LIST -200vom Anfang bis Zeile 200
LIST 100-ab Zeile 100 bis zum Ende

LOAD

LOAD "Name"

Lädt ein Programm von der Diskette. Das alte Programm im Speicher wird dabei ersetzt. Während des Ladens zeigt ein Balken den Fortschritt, am Ende steht LOADED. Der Name hat höchstens 16 Zeichen. Ohne Endung sucht der Computer zuerst Name.prg, dann Name.bas. Eine .prg-Datei enthält Maschinensprache (siehe Kapitel 7), eine .bas-Datei ein BASIC-Programm als Text. Groß- und Kleinschreibung zählt beim Namen, denn die Dateien liegen auf dem PC.

Fehlt die Datei, bleibt das alte Programm stehen, und es kommt FILE NOT FOUND. Ohne angeschlossene Diskette meldet der Computer NO DISK.

LOAD "galgen"lädt galgen.bas

NEW

NEW

Löscht das Programm und alle Variablen. Speichern Sie ein Programm, das Sie noch brauchen, vorher mit SAVE. Ein gelöschtes Programm lässt sich nicht zurückholen.

RUN

RUN [Zeile]

Startet das Programm im Speicher. Vorher setzt RUN alle Variablen auf 0 oder leer. Ohne Zahl beginnt das Programm bei der kleinsten Zeilennummer, mit Zahl bei dieser Zeile.

RUNstartet am Anfang
RUN 500startet bei Zeile 500

SAVE

SAVE "Name"

Speichert das Programm auf der Diskette. Die Datei ist reiner Text, eine Zeile pro Programmzeile, genau wie LIST sie zeigt. Sie können sie deshalb auch am PC lesen und ändern. Der Balken zeigt den Fortschritt, am Ende steht SAVED. Eine Datei mit demselben Namen wird überschrieben. Ist kein Programm im Speicher, steht NO PROGRAM.

SAVE "raten"speichert als raten.bas

Befehle

Die folgenden Befehle stehen meist in Programmzeilen. Die meisten gehen aber auch im Direktmodus. Mehrere Befehle in einer Zeile trennen Sie mit einem Doppelpunkt.

CLEAR

CLEAR

Löscht alle Variablen und Felder. Das Programm bleibt erhalten. RUN macht das automatisch.

CLS

CLS [#Gerät]

Löscht die Anzeige und setzt den Cursor nach links oben. Mit #1 ist immer das LCD gemeint, mit #2 das serielle Terminal (siehe Kapitel 6). Ohne Angabe gilt das Gerät, an dem Sie gerade arbeiten. Dasselbe gilt für LOCATE, CURSOR, PRINT und INPUT.

CURSOR

CURSOR [#Gerät] ON | OFF
CURSOR [#Gerät] BLINK ON | OFF

CURSOR ON und CURSOR OFF schalten den Unterstrich-Cursor ein und aus. CURSOR BLINK ON lässt zusätzlich das Zeichen an der Cursorstelle blinken, CURSOR BLINK OFF hört damit auf. Unterstrich und Blinken sind unabhängig voneinander. In Spielen schaltet man den Cursor meist aus, damit er nicht über die Anzeige springt. Nach dem Programm schalten Sie ihn mit CURSOR ON wieder ein.

DATA

DATA Wert, Wert, …

Legt eine Liste von Werten im Programm ab. READ liest sie der Reihe nach. Die Werte können Zahlen oder Texte sein. Texte brauchen nur dann Anführungszeichen, wenn sie ein Komma, einen Doppelpunkt oder Leerzeichen am Anfang oder Ende enthalten. DATA-Zeilen dürfen irgendwo im Programm stehen. Der Computer überspringt sie beim Ausführen.

10 DATA 12,14.5,"HALLO, DU",MAUS

DEF FN

DEF FNName(Variable) = Ausdruck

Legt eine eigene Rechenfunktion fest. Der Name ist ein Variablenname aus ein oder zwei Zeichen, davor steht FN. Die Variable in Klammern ist ein Platzhalter. Beim Aufruf setzt BASIC dort die Zahl ein, die Sie übergeben. Eine Funktion braucht genau eine Zahl und liefert eine Zahl. DEF FN geht nur in einem Programm, nicht im Direktmodus.

10 DEF FNQ(X)=X*X
20 PRINT FNQ(7)

schreibt 49.

DIM

DIM Name(Größe[, Größe …]) [, …]

Legt ein Feld an. Die Größe ist der höchste Index. DIM darf für jedes Feld nur einmal ausgeführt werden. Ein zweites Mal meldet ?REDIM'D ARRAY ERROR. Ein Index außerhalb der Größe ergibt ?BAD SUBSCRIPT ERROR. Mehrere Felder trennen Sie mit Kommas.

DIM A(50)51 Zahlen, A(0) bis A(50)
DIM W$(20),F%(3,3)21 Texte und 4×4 ganze Zahlen

DISPLAY

DISPLAY ON | OFF

Schaltet die Anzeige dunkel und wieder an. Der Text bleibt dabei gespeichert und ist nach DISPLAY ON sofort wieder da. So lässt sich eine Anzeige im Hintergrund aufbauen und dann auf einen Schlag zeigen.

EFFECT

EFFECT Nummer

Spielt einen eingebauten Klangeffekt. Er läuft auf Stimme 3 und im Hintergrund, das Programm läuft also sofort weiter. Die Stimmen 1 und 2 spielen ungestört weiter.

EFFECT 1Schuss
EFFECT 2Explosion
EFFECT 3Laser
EFFECT 4Sprung
EFFECT 5Münze
EFFECT 6Extra
EFFECT 7Fehler
EFFECT 8Sirene
EFFECT 9fallende Bombe

END

END

Beendet das Programm, ohne Meldung. END muss nicht am Schluss stehen. Man braucht es vor allem, damit ein Programm nicht in die Unterprogramme dahinter hineinläuft.

ENVELOPE

ENVELOPE Instrument, Attack, Decay, Sustain, Release

Stellt die Hüllkurve eines Instruments ein, also wie ein Ton lauter und leiser wird. Instrument 0 bis 7, jede Stufe 0 bis 15. Attack ist das Anschwellen, Decay das Abfallen auf die Haltelautstärke Sustain, Release das Ausklingen am Ende. Der nächste Ton mit diesem Instrument benutzt die neue Hüllkurve. Die Wellenform bleibt dabei unverändert.

ENVELOPE 4,0,9,0,0Instrument 4 wird ein kurzes Zupfen

FOR … TO … STEP

FOR Variable = Anfang TO Ende [STEP Schritt]

Beginnt eine Zählschleife. Die Variable bekommt zuerst den Anfangswert. Dann laufen die Befehle bis zum passenden NEXT. Dort wird der Schritt addiert. Ist die Variable danach noch nicht über das Ende hinaus, springt BASIC zurück hinter das FOR. Ohne STEP ist der Schritt 1. Mit einem negativen Schritt zählt die Schleife rückwärts. Die Schleife läuft immer mindestens einmal durch.

FOR I=1 TO 101, 2, 3 … 10
FOR I=0 TO 1 STEP 0.250, 0.25, 0.5, 0.75, 1
FOR I=10 TO 1 STEP -310, 7, 4, 1

GOSUB

GOSUB Zeile

Springt in ein Unterprogramm, das bei der angegebenen Zeile beginnt. Trifft BASIC dort auf RETURN, geht es hinter dem GOSUB weiter. Unterprogramme dürfen selbst wieder GOSUB benutzen.

10 GOSUB 100:GOSUB 100:END
100 PRINT "HALLO":RETURN

GOTO

GOTO Zeile

Springt zu einer Zeile und macht dort weiter. Gibt es die Zeile nicht, meldet BASIC ?UNDEF'D STATEMENT ERROR. Statt GOTO dürfen Sie auch GO TO schreiben. Im Direktmodus startet GOTO das Programm bei dieser Zeile, ohne die Variablen zu löschen.

IF … THEN

IF Bedingung THEN Befehle
IF Bedingung THEN Zeile
IF Bedingung GOTO Zeile

Prüft eine Bedingung. Stimmt sie, führt BASIC die Befehle hinter THEN aus oder springt zur angegebenen Zeile. Stimmt sie nicht, geht es in der nächsten Zeile weiter. Alle Befehle hinter THEN in derselben Zeile gehören also zur Bedingung. Als Bedingung zählt jede Zahl: 0 heißt „stimmt nicht“, alles andere „stimmt“.

IF A>10 THEN PRINT "ZU GROSS":A=10
IF K=27 THEN 900springt zu Zeile 900
IF A$="J" AND P>0 GOTO 50

INPUT

INPUT [#Gerät,] ["Text";] Variable, …

Wartet auf eine Eingabe über die Tastatur. Der Text erscheint als Frage, dahinter ein Fragezeichen. Was Sie bis Enter tippen, landet in der Variablen. Bei mehreren Variablen trennen Sie die Eingaben mit Kommas. Tippen Sie zu wenige, fragt der Computer mit ?? nach dem Rest. Tippen Sie Buchstaben, wo eine Zahl erwartet wird, kommt ?REDO FROM START, und Sie geben alles noch einmal ein. INPUT geht nur in einem Programm.

INPUT "DEIN NAME";N$fragt nach einem Text
INPUT X,Yzwei Zahlen, zum Beispiel 3,4
INPUT #1,A$liest immer von der Tastatur

LED

LED ON | OFF

Schaltet die LED oben rechts ein oder aus. Nach dem Einschalten leuchtet sie eine Sekunde lang von selbst. Der erste LED-Befehl übernimmt sie danach ganz.

LET

[LET] Variable = Ausdruck

Gibt einer Variablen einen Wert. Das Wort LET dürfen Sie weglassen, LET A=5 und A=5 tun dasselbe. Zahlen und Texte dürfen Sie nicht mischen. A="X" ergibt ?TYPE MISMATCH ERROR.

A=A+1zählt A um eins hoch
N$="OTTO"

LOCATE

LOCATE [#Gerät,] Zeile, Spalte

Setzt den Cursor. Das nächste PRINT schreibt an diese Stelle. Auf dem LCD geht die Zeile von 0 bis 3 und die Spalte von 0 bis 39. Auf dem seriellen Terminal gelten die Grenzen von TERM.

LOCATE 3,35:PRINT "ENDE";schreibt rechts unten

NEXT

NEXT [Variable] [, Variable …]

Schließt eine FOR-Schleife ab. Die Variable dürfen Sie weglassen, dann gehört NEXT zur innersten Schleife. NEXT J,I schließt zwei verschachtelte Schleifen auf einmal. Passt die Variable zu keinem FOR, meldet BASIC ?NEXT WITHOUT FOR ERROR.

ON

ON Ausdruck GOTO Zeile, Zeile, …
ON Ausdruck GOSUB Zeile, Zeile, …

Ein Verteiler. Ist der Ausdruck 1, springt BASIC zur ersten Zeile der Liste, bei 2 zur zweiten und so weiter. Nachkommastellen fallen weg. Ist der Wert 0 oder größer als die Liste lang, geht es einfach mit dem nächsten Befehl weiter.

ON W GOSUB 100,200,300W=2 ruft Zeile 200 auf

PLAY

PLAY Platz [ON | OFF] [, …]

Spielt eine Melodie, die Sie vorher mit TUNE abgelegt haben. Platz 1 bis 3 ist zugleich die Stimme. Die Melodie läuft im Hintergrund, das Programm geht sofort weiter. Mit ON wiederholt sie sich ohne Ende. PLAY Platz OFF hält eine Stimme an, PLAY 0 alle drei.

PLAY 1Platz 1 einmal spielen
PLAY 1 ON,2Platz 1 wiederholen, Platz 2 einmal
PLAY 2 OFFnur Stimme 2 anhalten
PLAY 0alle anhalten

POKE

POKE Adresse, Wert

Schreibt ein Byte in den Speicher. Die Adresse geht von 0 bis 65535, der Wert von 0 bis 255. Vorsicht: Ein POKE an die falsche Stelle kann BASIC durcheinanderbringen. Dann hilft nur ein Reset. Der Computer nimmt dabei keinen Schaden, das Programm im Speicher ist danach aber meist verloren. Welche Adressen wofür da sind, zeigt Anhang C.

PRINT

PRINT [#Gerät,] [Ausdruck] [; | ,] …

Schreibt Zahlen und Texte auf die Anzeige. Statt PRINT dürfen Sie ? tippen. Was zwischen den Ausdrücken steht, bestimmt den Abstand:

;schreibt direkt dahinter weiter
,springt zur nächsten Spalte 0, 10, 20 oder 30
nichts am Endenach der Ausgabe in die nächste Zeile

Zahlen bekommen vorn ein Leerzeichen, wenn sie positiv sind, und hinten immer eines. Eine Zeile, die länger als 40 Zeichen ist, geht auf der Anzeige in der nächsten Zeile weiter. TAB und SPC helfen beim Ausrichten (siehe Funktionen).

PRINT "SUMME:";A+B
PRINT "A","B","C"drei Spalten
PRINT #2,"AN DEN PC"schreibt auf das serielle Terminal

QUIT

QUIT

Beendet das serielle BASIC-Terminal (Kapitel 6). Die Leitung geht zurück an den Monitor, und BASIC benutzt wieder Tastatur und LCD. Das Programm im Speicher bleibt erhalten. serial-basic.sh sendet QUIT von selbst, wenn Sie das Terminal verlassen. Ohne serielles Terminal ist QUIT ein ?SYNTAX ERROR.

READ

READ Variable, …

Liest den nächsten Wert aus den DATA-Zeilen in eine Variable. Jedes READ rückt in der Liste weiter. Sind alle Werte gelesen, meldet BASIC ?OUT OF DATA ERROR. Die Art der Variable muss zum Wert passen: Ein Text lässt sich nicht in eine Zahlenvariable lesen.

10 FOR I=1 TO 3:READ N$:PRINT N$:NEXT
20 DATA ANNA,BERT,CARLA

REM

REM Text

Eine Bemerkung für Menschen. BASIC überspringt alles hinter REM bis zum Ende der Zeile, auch Doppelpunkte und Befehle. Bemerkungen kosten Speicher, machen ein Programm aber viel verständlicher.

10 REM *** GALGENRATEN ***

RESTORE

RESTORE

Setzt das Lesen der DATA-Zeilen zurück. Das nächste READ liest wieder den ersten Wert im Programm.

RETURN

RETURN

Beendet ein Unterprogramm. BASIC macht hinter dem GOSUB weiter, das es aufgerufen hat. Ein RETURN ohne GOSUB ergibt ?RETURN WITHOUT GOSUB ERROR. Das passiert oft, wenn vor den Unterprogrammen das END fehlt.

SLEEP

SLEEP Sekunden

Wartet eine Zeit lang. Auch Bruchteile gehen: SLEEP 0.1 wartet eine Zehntelsekunde. Melodien und Effekte spielen während des Wartens weiter. Pause bricht das Warten ab.

SOUND

SOUND Stimme, Frequenz, Dauer [, Instrument]

Spielt einen Ton auf Stimme 1, 2 oder 3. Der Ton läuft im Hintergrund, das Programm geht sofort weiter. Die Frequenz ist die Zahl, die der SID-Chip erwartet, von 0 bis 65535. Sie ist etwa 16,78-mal die Frequenz in Hertz. Das eingestrichene C (261,6 Hz) ist 4389. Die Dauer zählt in Sechzehnteln, 1 bis 255, und hängt von TEMPO ab. Das Instrument (0 bis 7) wählt Wellenform und Hüllkurve. Ohne Instrument behält die Stimme ihre Klangfarbe. Die Frequenzen einer ganzen Tonleiter stehen in Kapitel 5.

SOUND 1,4389,8,1ein C auf dem Klavier, eine Sekunde lang

STOP

STOP

Hält das Programm an und meldet BREAK IN mit der Zeilennummer, so wie die Taste Pause. Mit CONT läuft es weiter. STOP hilft bei der Fehlersuche: Sie halten das Programm an einer bestimmten Stelle an und sehen sich die Variablen an.

SYS

SYS Adresse

Startet ein Maschinenprogramm an der Adresse (0 bis 65535). Endet es mit dem Befehl RTS, geht es im BASIC-Programm weiter. Mehr dazu in Kapitel 7.

TEMPO

TEMPO n

Legt fest, wie viele Sechzehntel pro Sekunde vergehen, von 1 bis 50. Nach dem Einschalten ist es 8. Das Tempo gilt für die Dauer bei SOUND und für die Notenlängen bei TUNE, nicht für EFFECT.

TERM

TERM [Spalten [, Zeilen]]

Gibt die Größe des seriellen Terminals an. Nach dem Start sind das 80 Spalten und 24 Zeilen. Danach richten sich PRINT, LOCATE und das Umbrechen langer Zeilen. Ohne Zahlen schreibt TERM die aktuelle Größe hin. Das Terminalfenster am PC muss mindestens so groß sein.

TUNE

TUNE Platz, "Noten"

Legt eine Melodie auf Platz 1, 2 oder 3 ab. PLAY spielt sie dann. Die Noten sind ein Text mit höchstens 47 Zeichen. Leerzeichen werden übersprungen, groß oder klein ist egal.

C D E F G A BNoten, B ist das deutsche H
C#eine Note um einen Halbton höher
C5Note mit Oktave 0 bis 7
O3Oktave für die folgenden Noten
L8Länge in Sechzehnteln, 1 bis 8
I1Instrument 0 bis 7
R2Pause, hier zwei Sechzehntel lang

Am Anfang gelten Oktave 4, Länge 4 und Instrument 0. Eine Angabe gilt, bis eine neue kommt.

TUNE 1,"L4CDEFL8GG"Anfang von „Alle meine Entchen“

VOL

VOL Stufe

Stellt die Gesamtlautstärke aller drei Stimmen ein, von 0 (stumm) bis 15 (laut). Nach dem Einschalten ist sie 15. Wie laut der Lautsprecher insgesamt ist, bestimmt der Drehregler am Gerät.

WAIT

WAIT Adresse, Maske [, Umkehr]

Wartet, bis an einer Speicheradresse bestimmte Bits gesetzt sind. BASIC liest das Byte immer wieder, verknüpft es mit Umkehr per XOR und dann mit Maske per AND. Sobald das Ergebnis nicht 0 ist, geht es weiter. Das ist ein Befehl für Fortgeschrittene, der mit der Hardware arbeitet. Wartet er ewig, hilft Pause.

WAVE

WAVE Stimme, Form [, Pulsbreite]

Ändert die Wellenform einer Stimme sofort, auch mitten in einem Ton. Form 0 ist Dreieck, 1 Sägezahn, 2 Puls, 3 Rauschen. Die Pulsbreite (0 bis 4095) hört man nur bei Form 2. 2048 ergibt einen gleichmäßigen Rechteckton. Der nächste Ton mit Instrumentnummer stellt wieder die Wellenform des Instruments ein.

Funktionen

Eine Funktion liefert einen Wert. Sie steht deshalb nie allein, sondern immer in einem Ausdruck, zum Beispiel hinter PRINT oder rechts vom Gleichheitszeichen. Die Werte, mit denen sie rechnet, stehen in Klammern.

Rechenfunktionen

ABS(x)Betrag: x ohne Vorzeichen. ABS(-7) ist 7.
ATN(x)Arkustangens von x, im Bogenmaß.
COS(x)Kosinus. x ist im Bogenmaß, ein Vollkreis ist 2π, etwa 6.283.
EXP(x)e (2.71828…) hoch x.
FNName(x)Eine eigene Funktion, festgelegt mit DEF FN.
INT(x)Größte ganze Zahl, die nicht größer als x ist. INT(3.7) ist 3, INT(-3.7) ist −4.
LOG(x)Natürlicher Logarithmus. x muss größer als 0 sein. Den Zehnerlogarithmus erhalten Sie mit LOG(x)/LOG(10).
RND(x)Zufallszahl zwischen 0 und 1 (ohne die 1). Bei positivem x kommt die nächste Zahl. Ein negatives x legt einen Startwert fest, x=0 wiederholt die letzte Zahl. Eine ganze Zufallszahl von 1 bis 6: INT(RND(1)*6)+1.
SGN(x)Vorzeichen: −1, wenn x negativ ist, 0 bei 0, sonst 1.
SIN(x)Sinus, x im Bogenmaß.
SQR(x)Quadratwurzel. x darf nicht negativ sein.
TAN(x)Tangens, x im Bogenmaß.
USR(x)Ruft ein Maschinenprogramm auf und gibt ihm x mit. Die Startadresse steht in den Speicherstellen 11 (niedriges Byte) und 12 (hohes Byte). Siehe Kapitel 7.

Textfunktionen

ASC(t$)Zeichencode des ersten Zeichens. ASC("A") ist 65. Die Codes stehen in Anhang D.
CHR$(n)Das Zeichen mit dem Code n (0 bis 255). CHR$(65) ist "A".
LEFT$(t$,n)Die ersten n Zeichen. LEFT$("HAUSTIER",4) ist "HAUS".
LEN(t$)Anzahl der Zeichen. LEN("OTTO") ist 4.
MID$(t$,a[,n])n Zeichen ab dem a-ten Zeichen. Das erste Zeichen ist Nummer 1. Ohne n geht es bis zum Ende. MID$("HAUSTIER",5,3) ist "TIE".
RIGHT$(t$,n)Die letzten n Zeichen. RIGHT$("HAUSTIER",4) ist "TIER".
STR$(x)Die Zahl als Text, genau so, wie PRINT sie schreiben würde. Positive Zahlen beginnen mit einem Leerzeichen: STR$(42) ist " 42".
VAL(t$)Die Zahl am Anfang des Textes. VAL("12.5KG") ist 12.5. Beginnt der Text nicht mit einer Zahl, ist das Ergebnis 0.

Weitere Funktionen

FRE(0)Wie viele Bytes Speicher noch frei sind. Die Zahl in Klammern spielt keine Rolle.
KEY(0)Der Code der Taste, die gerade gedrückt ist, oder 0. KEY wartet nicht. Die Pfeiltasten liefern 17 bis 20, die übrigen Codes stehen in Kapitel 4 und Anhang E.
PEEK(a)Das Byte an der Speicheradresse a (0 bis 65535), eine Zahl von 0 bis 255.
POS(0)Die Spalte, in der der Cursor gerade steht. Die erste Spalte ist 0.

Ausgabefunktionen

Diese beiden gehen nur innerhalb von PRINT.

Nicht in diesem BASIC

Wer BASIC vom C64 kennt, vermisst vielleicht ein paar Befehle. GET gibt es nicht, dafür nimmt man KEY(0). CLR heißt hier CLEAR. OPEN, CLOSE, CMD und VERIFY fehlen ebenfalls. TI und ST sind hier ganz gewöhnliche Variablen ohne besondere Bedeutung. Die Diskette erreichen Sie über LOAD, SAVE, DIR und DELETE.
