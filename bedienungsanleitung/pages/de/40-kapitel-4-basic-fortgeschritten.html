Mit Variablen, Schleifen, IF und INPUT können Sie schon viel anfangen. In diesem Kapitel kommen die Werkzeuge dazu, mit denen größere Programme übersichtlich bleiben: Felder für viele Werte, Unterprogramme, Daten im Programm, eigene Funktionen und Zufall. Danach lernen Sie, die Anzeige gezielt zu beschreiben, die Tastatur direkt abzufragen und die LED zu schalten. Am Ende steht ein Spiel, das all das zusammenbringt.

Felder mit DIM

Wollen Sie fünf Punktzahlen speichern, könnten Sie fünf Variablen nehmen: P1, P2 und so weiter. Einfacher ist ein Feld. Das ist eine Variable mit mehreren Fächern, die über eine Nummer angesprochen werden, den Index:

10 DIM P(4)
20 S=0
30 FOR I=0 TO 4
40 INPUT "PUNKTE";P(I)
50 S=S+P(I)
60 NEXT I
70 PRINT "DURCHSCHNITT:";S/5
80 FOR I=0 TO 4
90 IF P(I)>S/5 THEN PRINT "WERT";I+1;"LIEGT DARUEBER"
100 NEXT I

DIM P(4) legt ein Feld mit den Fächern P(0) bis P(4) an, also fünf Stück. Der Index darf eine Variable oder eine Rechnung sein. Genau das macht Felder so nützlich: Eine Schleife kann alle Fächer der Reihe nach bearbeiten.

  • Ein Feld ohne DIM hat die Fächer 0 bis 10.
  • Ein Index außerhalb des Feldes führt zu ?BAD SUBSCRIPT ERROR.
  • Jedes Feld darf nur einmal mit DIM angelegt werden. Ein zweites Mal ist ?REDIM'D ARRAY ERROR. RUN und CLEAR löschen alle Felder.
  • Felder gibt es für alle drei Arten von Variablen: DIM N$(20) für Texte, DIM Z%(100) für ganze Zahlen.
  • Ein Feld kann auch zwei Indizes haben, wie eine Tabelle mit Zeilen und Spalten: DIM F(2,3), dann F(2,3)=7.

Unterprogramme

Oft braucht ein Programm dieselben Befehle an mehreren Stellen. Statt sie mehrmals zu schreiben, legen Sie sie als Unterprogramm ab. GOSUB springt hinein, RETURN springt zurück hinter das GOSUB:

10 PRINT "ANFANG"
20 GOSUB 100
30 PRINT "MITTE"
40 GOSUB 100
50 END
100 PRINT "--------"
110 RETURN

Wichtig ist das END in Zeile 50. Ohne diese Zeile liefe das Programm nach dem zweiten Aufruf einfach weiter in das Unterprogramm hinein. Beim RETURN wüsste es dann nicht, wohin zurück, und meldet ?RETURN WITHOUT GOSUB ERROR. Man legt Unterprogramme deshalb ans Ende und setzt davor ein END.

Ein Unterprogramm darf selbst wieder GOSUB benutzen. Jedes RETURN kehrt zum jeweils letzten GOSUB zurück.

Verteiler mit ON

ON wählt anhand einer Zahl eines von mehreren Sprungzielen:

ON W GOSUB 100,200,300

Ist W gleich 1, geht es zu Zeile 100. Bei 2 zu Zeile 200, bei 3 zu Zeile 300. Ist W gleich 0 oder größer als die Zahl der Ziele, passiert nichts, und das Programm macht mit dem nächsten Befehl weiter. Kommazahlen werden abgerundet. ON W GOTO … funktioniert genauso, nur ohne Rückkehr.

DATA und READ

Manche Werte stehen schon fest, wenn Sie das Programm schreiben: eine Wortliste, die Namen der Wochentage, die Töne einer Melodie. Solche Werte schreiben Sie hinter DATA. READ liest sie der Reihe nach in Variablen:

10 DIM T$(6)
20 FOR I=0 TO 6:READ T$(I):NEXT I
30 INPUT "TAG (1-7)";N
40 IF N<1 OR N>7 THEN 30
50 PRINT "DAS IST ";T$(N-1)
60 DATA MONTAG,DIENSTAG,MITTWOCH,DONNERSTAG
70 DATA FREITAG,SAMSTAG,SONNTAG

Wo die DATA-Zeilen stehen, ist egal. Der Computer liest sie in der Reihenfolge der Zeilennummern, über alle DATA-Zeilen hinweg. Ein paar Regeln:

  • Die Werte werden durch Kommas getrennt. Enthält ein Text selbst ein Komma, setzen Sie ihn in Anführungszeichen: DATA "KIRSCHE, SUESS",3.
  • Text hinter DATA bleibt so, wie Sie ihn tippen, klein oder groß. Soll das Programm ihn später mit großen Buchstaben vergleichen, tippen Sie ihn mit Shift.
  • RESTORE setzt den Lesezeiger zurück an den Anfang. Das nächste READ liest wieder den ersten Wert.
  • Sind alle Werte gelesen, führt ein weiteres READ zu ?OUT OF DATA ERROR.

Weiß man vorher nicht, wie viele Werte es sind, setzt man ein Endezeichen ans Ende der Liste, zum Beispiel *, und liest, bis es kommt. Das Spiel am Ende dieses Kapitels macht es so.

Funktionen

Eine Funktion nimmt einen Wert in Klammern und liefert ein Ergebnis zurück. Sie steht überall dort, wo eine Zahl stehen darf: PRINT SQR(16), A=INT(X). Die wichtigsten Rechenfunktionen:

FunktionErgebnisBeispiel
INT(x)größte ganze Zahl, die nicht größer als x istINT(3.7) = 3, INT(-3.7) = −4
ABS(x)Betrag, ohne VorzeichenABS(-4) = 4
SGN(x)Vorzeichen: −1, 0 oder 1SGN(-2) = −1
SQR(x)QuadratwurzelSQR(16) = 4
SIN, COS, TAN, ATNWinkelfunktionen, Winkel im BogenmaßATN(1)*4 = 3.14159266
EXP(x), LOG(x)e hoch x, natürlicher Logarithmus

Potenzen schreiben Sie mit ^: 2^10 ist 1024. Den Rest einer Division gibt es nicht als eigene Funktion. Sie bekommen ihn mit A-INT(A/B)*B. Für 17 geteilt durch 5 ist das 2.

Eigene Funktionen mit DEF FN

Eine Rechnung, die Sie oft brauchen, können Sie als eigene Funktion festlegen. Der Name beginnt mit FN, dahinter folgt ein Variablenname:

10 DEF FNQ(A)=A*A
20 PRINT FNQ(7)

Das gibt 49 aus. Das A in der Klammer ist nur ein Platzhalter. Beim Aufruf steht dort der Wert, den Sie übergeben. Eine Funktion hat genau einen solchen Wert. DEF FN geht nur in einem Programm, direkt eingetippt meldet der Computer ?ILLEGAL DIRECT ERROR.

Zufallszahlen

RND(1) liefert eine Zufallszahl, die mindestens 0 und kleiner als 1 ist. Für einen Würfel brauchen Sie aber die ganzen Zahlen von 1 bis 6. Die Formel dafür lautet:

INT(RND(1)*6)+1

RND(1)*6 ergibt eine Zahl von 0 bis knapp unter 6. INT schneidet die Nachkommastellen ab, übrig bleiben 0 bis 5. Plus eins ergibt 1 bis 6. Allgemein bekommen Sie mit INT(RND(1)*N)+1 eine Zahl von 1 bis N. Als eigene Funktion:

10 DEF FNW(X)=INT(RND(1)*X)+1
20 FOR I=1 TO 10:PRINT FNW(6);:NEXT I

Der Startwert

Die Zahlen von RND sind nicht wirklich zufällig. Sie werden aus einem Startwert berechnet. Nach dem Einschalten ist das immer derselbe, darum kommen immer dieselben Zahlen. Mit einer negativen Zahl in der Klammer setzen Sie einen neuen Startwert: X=RND(-42). Derselbe Startwert ergibt dieselbe Folge. Das ist praktisch zum Testen.

Für echten Zufall braucht man einen Startwert, den niemand vorhersagen kann. Ein bewährter Trick: Das Programm zählt, bis Sie eine Taste drücken. Wie lange das dauert, ist jedes Mal anders:

10 PRINT "BITTE EINE TASTE DRUECKEN."
20 S=0
30 S=S+1:IF KEY(0)=0 THEN 30
40 X=RND(-S)

Wie KEY funktioniert, steht weiter unten in diesem Kapitel. RND(0) liefert übrigens noch einmal die letzte Zufallszahl.

Zeichenketten

Auch mit Texten lässt sich rechnen. Diese Funktionen zerlegen, prüfen und verwandeln sie:

FunktionErgebnisBeispiel
LEN(a$)Anzahl der ZeichenLEN("HALLO") = 5
LEFT$(a$,n)die ersten n ZeichenLEFT$("HALLO",2) = HA
RIGHT$(a$,n)die letzten n ZeichenRIGHT$("HALLO",3) = LLO
MID$(a$,p,n)n Zeichen ab Stelle pMID$("HALLO",2,3) = ALL
MID$(a$,p)alles ab Stelle pMID$("HALLO",4) = LO
ASC(a$)Zeichencode des ersten ZeichensASC("A") = 65

Die Stellen in einem Text zählen ab 1. STR$ setzt vor positive Zahlen ein Leerzeichen, so wie PRINT. VAL liest die Zahl am Anfang des Textes. Steht dort keine, ist das Ergebnis 0. Jeder Buchstabe hat einen Zeichencode: A bis Z sind 65 bis 90, a bis z sind 97 bis 122. Den Zeichensatz finden Sie in Anhang D.

Dieses Programm schreibt ein Wort rückwärts. Die Schleife läuft von hinten nach vorn und holt mit MID$ jeweils ein Zeichen:

10 INPUT "WORT";W$
20 FOR I=LEN(W$) TO 1 STEP -1
30 PRINT MID$(W$,I,1);
40 NEXT I
50 PRINT

Die Anzeige steuern

Bisher hat PRINT einfach Zeile für Zeile geschrieben, und die Anzeige ist nach oben weitergerollt. Für Spiele und übersichtliche Ausgaben wollen Sie aber selbst bestimmen, wo etwas steht. Dafür gibt es diese Befehle:

BefehlWirkung
CLSAnzeige löschen, Cursor nach links oben
LOCATE z,sCursor in Zeile z (0 bis 3) und Spalte s (0 bis 39) setzen
CURSOR OFF / CURSOR ONUnterstrich-Cursor aus- und einschalten
CURSOR BLINK ON / OFFZeichen unter dem Cursor blinken lassen
DISPLAY OFF / DISPLAY ONAnzeige dunkel schalten und wieder an. Der Text bleibt erhalten.
SLEEP ss Sekunden warten, auch Bruchteile: SLEEP 0.1

Dieses Programm zählt die Sekunden, immer an derselben Stelle:

10 CLS:CURSOR OFF
20 T=0
30 LOCATE 1,14:PRINT "SEKUNDEN:";T;
40 SLEEP 1:T=T+1:GOTO 30

Achten Sie auf das Semikolon am Ende von Zeile 30. Ohne Semikolon setzt PRINT den Cursor in die nächste Zeile. In der untersten Zeile rollt dann die ganze Anzeige nach oben. Wenn Sie mit LOCATE arbeiten, beenden Sie PRINT deshalb immer mit ;.

Wenn Sie das Programm mit Pause anhalten, bleibt der Cursor ausgeschaltet. Tippen Sie CURSOR ON, dann ist er wieder da.

Tipp

Innerhalb von PRINT gibt es noch TAB(n) und SPC(n). TAB(10) rückt bis Spalte 10 vor, SPC(3) schreibt drei Leerzeichen. POS(0) verrät, in welcher Spalte der Cursor gerade steht.

Die Tastatur abfragen

INPUT wartet, bis Sie Enter drücken. Für ein Spiel ist das zu langsam. Die Funktion KEY(0) schaut stattdessen nach, welche Taste in diesem Moment gedrückt ist, und wartet nicht. Ist keine gedrückt, liefert sie 0, sonst den Zeichencode der Taste. Die Zahl in der Klammer spielt keine Rolle.

Dieses Programm zeigt die Codes der Tasten, die Sie drücken:

10 CLS:CURSOR OFF
15 IF KEY(0)<>0 THEN 15
20 K=KEY(0):IF K=0 THEN 20
30 PRINT K;
40 IF KEY(0)<>0 THEN 40
50 GOTO 20

Zeile 20 wartet, bis eine Taste gedrückt ist. Zeile 40 wartet, bis sie wieder losgelassen ist. Ohne Zeile 40 würde das Programm den Code immer wieder ausgeben, solange Sie die Taste halten. Zeile 15 wartet am Anfang, bis Sie Enter nach dem RUN losgelassen haben. Sonst wäre die erste Zahl immer 13.

TasteCodeTasteCode
A bis Z97 bis 122←17
Shift + A bis Z65 bis 90→18
0 bis 948 bis 57↑19
Enter13↓20
Leertaste32Pos121
Esc27Ende22
Rücktaste8Entf23
Einfg24

Weil KEY meldet, solange eine Taste gedrückt ist, eignet es sich gut für Bewegungen. Hier wandert ein Stern mit den Pfeiltasten über die Anzeige. Halten Sie die Taste fest, läuft er weiter. Esc beendet das Programm:

10 CLS:CURSOR OFF:X=20:Y=1
20 LOCATE Y,X:PRINT "*";
30 K=KEY(0):IF K=0 THEN 30
40 LOCATE Y,X:PRINT " ";
50 IF K=17 AND X>0 THEN X=X-1
60 IF K=18 AND X<39 THEN X=X+1
70 IF K=19 AND Y>0 THEN Y=Y-1
80 IF K=20 AND Y<3 THEN Y=Y+1
90 IF K=27 THEN CLS:CURSOR ON:END
100 SLEEP 0.1:GOTO 20

Zeile 40 löscht den Stern an der alten Stelle, bevor die Zeilen 50 bis 80 die neue ausrechnen. Die Bedingungen hinter AND halten ihn innerhalb der Anzeige. Das SLEEP in Zeile 100 bremst ihn. Ohne diese Zeile springt er schon bei einem kurzen Tastendruck mehrere Felder weit.

Die LED

Oben rechts am Gerät sitzt eine LED. Nach dem Einschalten und nach einem Reset leuchtet sie eine Sekunde lang von selbst. Danach gehört sie Ihnen: LED ON schaltet sie ein, LED OFF schaltet sie aus.

10 LED ON
20 SLEEP 0.5
30 LED OFF
40 SLEEP 0.5
50 GOTO 10

Das Programm lässt die LED im Sekundentakt blinken, bis Sie es anhalten. Sie können die LED als Signal nutzen, etwa wenn ein Spiel gewonnen ist, oder um zu zeigen, dass ein langes Programm noch arbeitet.

Hinweis

ON und OFF sind BASIC-Wörter. Eine Variable darf deshalb nicht OFF heißen.

Ein Spiel: Galgenraten

Zum Abschluss ein größeres Programm, das fast alles aus diesem und dem letzten Kapitel benutzt. Der Computer wählt ein Wort. Sie raten Buchstabe für Buchstabe. Jeder Buchstabe, der nicht im Wort vorkommt, ist ein Fehler. Nach acht Fehlern haben Sie verloren.

Das Programm ist lang. Tippen Sie es in Ruhe ab und prüfen Sie jeden Abschnitt mit LIST. Sie finden es auch im Firmware-Projekt als examples/galgen.bas. Ist das Laufwerk aus Kapitel 6 verbunden, laden Sie es mit LOAD "galgen". Die Abschnitte im Einzelnen:

Vorbereitung

10 REM GALGENRATEN
20 DIM WL$(20),G(25)
30 DEF FNR(X)=INT(RND(1)*X)
40 N=0
50 READ A$:IF A$="*" THEN 80
60 N=N+1:WL$(N)=A$
70 GOTO 50
80 CLS:CURSOR OFF
90 PRINT "GALGENRATEN":PRINT
100 PRINT "BITTE EINE TASTE DRUECKEN."
105 IF KEY(0)<>0 THEN 105
110 S=0
120 S=S+1:IF KEY(0)=0 THEN 120
130 X=RND(-S)
140 IF KEY(0)<>0 THEN 140

Zeile 20 legt zwei Felder an. WL$ ist die Wortliste. G hat ein Fach für jeden Buchstaben von A bis Z. Dort steht später eine 1, wenn der Buchstabe schon geraten wurde. Zeile 30 legt eine Funktion für Zufallszahlen von 0 bis X−1 fest. Die Zeilen 50 bis 70 lesen die Wörter aus den DATA-Zeilen, bis das Endezeichen * kommt. N zählt dabei mit. Die Zeilen 105 bis 140 erzeugen den Startwert für den Zufall mit dem Tastentrick von oben.

Eine Runde

200 REM NEUE RUNDE
210 W$=WL$(FNR(N)+1):L=LEN(W$)
220 FOR I=0 TO 25:G(I)=0:NEXT I
230 F=0:R$="":CLS
240 GOSUB 500
250 IF M=0 THEN E=1:GOTO 400
260 IF F=8 THEN E=2:GOTO 400
270 LOCATE 3,0:PRINT "BUCHSTABE?        ";
280 GOSUB 600
290 B=ASC(B$)-65
300 IF G(B)=1 THEN 280
310 G(B)=1:T=0
320 FOR I=1 TO L
330 IF MID$(W$,I,1)=B$ THEN T=1
340 NEXT I
350 IF T=0 THEN F=F+1:R$=R$+B$
360 GOTO 240

Zeile 210 wählt ein zufälliges Wort W$ mit der Länge L. Zeile 220 vergisst alle geratenen Buchstaben, Zeile 230 setzt die Fehler F und die Liste der falschen Buchstaben R$ zurück. Dann beginnt die Schleife von Zeile 240 bis 360: Anzeige auffrischen, prüfen, ob die Runde vorbei ist, einen Buchstaben holen.

Zeile 290 macht aus dem Buchstaben eine Zahl von 0 (A) bis 25 (Z), passend zum Feld G. Wurde der Buchstabe schon geraten, holt Zeile 300 einfach den nächsten. Die Zeilen 320 bis 340 prüfen jede Stelle des Wortes. T wird 1, sobald der Buchstabe irgendwo vorkommt.

Achtung, Falle

Das NEXT I steht absichtlich in einer eigenen Zeile. Stünde es in Zeile 330 hinter dem IF, würde es nur ausgeführt, wenn die Bedingung wahr ist. Bei jedem anderen Buchstaben bliebe die Schleife hängen.

Ende der Runde

400 ON E GOSUB 700,800
410 LOCATE 3,0:PRINT "NOCH EINMAL (J/N)?";
420 GOSUB 600
430 IF B$="J" THEN 200
440 IF B$<>"N" THEN 420
450 CLS:CURSOR ON:END

E ist 1, wenn alle Buchstaben gefunden sind, und 2 nach acht Fehlern. ON E GOSUB springt in das passende Unterprogramm. Danach fragt das Programm nach einer neuen Runde. Jede andere Taste als J und N wird überhört.

Die Unterprogramme

500 REM ANZEIGE
510 LOCATE 0,0:PRINT "GALGENRATEN";
520 LOCATE 0,27:PRINT "FEHLER";F;"/ 8";
530 LOCATE 1,0:M=0
540 FOR I=1 TO L:C$=MID$(W$,I,1)
550 IF G(ASC(C$)-65)=1 THEN PRINT C$;" ";:GOTO 570
560 PRINT "_ ";:M=M+1
570 NEXT I
580 LOCATE 2,0:PRINT "FALSCH: ";R$;
590 RETURN

Das Unterprogramm ab Zeile 500 zeichnet die Anzeige. Für jede Stelle des Wortes schreibt es den Buchstaben, wenn er schon geraten ist, sonst einen Strich. M zählt dabei die Striche. Ist M am Ende 0, ist das Wort vollständig.

600 REM TASTE HOLEN
610 K=KEY(0):IF K=0 THEN 610
620 IF KEY(0)<>0 THEN 620
630 IF K>=97 AND K<=122 THEN K=K-32
640 IF K<65 OR K>90 THEN 610
650 B$=CHR$(K):RETURN

Das Unterprogramm ab Zeile 600 wartet auf eine Taste und auf das Loslassen. Zeile 630 macht aus kleinen Buchstaben große, denn die Codes liegen genau 32 auseinander. Zeile 640 lässt nur Buchstaben durch. So funktioniert das Spiel mit und ohne Shift.

700 REM GEWONNEN
710 LOCATE 3,0:PRINT "RICHTIG!          ";
720 FOR I=1 TO 5:LED ON:SLEEP 0.2:LED OFF:SLEEP 0.2:NEXT I
730 RETURN
800 REM VERLOREN
810 FOR I=0 TO 25:G(I)=1:NEXT I
820 GOSUB 500
830 LOCATE 3,0:PRINT "LEIDER VERLOREN.  ";
840 SLEEP 2
850 RETURN

Beim Gewinnen blinkt die LED fünfmal. Beim Verlieren markiert Zeile 810 einfach alle Buchstaben als geraten. Dann zeigt das Anzeige-Unterprogramm das ganze Wort, ohne dass dafür neuer Code nötig ist. Die Leerzeichen hinter den Meldungen überschreiben Reste der vorigen Zeile.

Die Wortliste

900 DATA COMPUTER,PROZESSOR,TASTATUR,SPEICHER
910 DATA PROGRAMM,SCHLEIFE,VARIABLE,ANZEIGE
920 DATA DISKETTE,MONITOR,ZEICHEN,KLANG
930 DATA *

Eigene Wörter fügen Sie einfach als weitere DATA-Zeilen vor Zeile 930 ein. Drei Regeln gelten: nur große Buchstaben von A bis Z, keine Umlaute, höchstens 20 Buchstaben, sonst passt das Wort nicht in eine Zeile. Insgesamt passen 20 Wörter in das Feld. Für mehr vergrößern Sie WL$ in Zeile 20.

Was in diesem Programm steckt: Felder (DIM), Unterprogramme (GOSUB, ON … GOSUB), Daten (DATA, READ), eine eigene Funktion (DEF FN), Zufall mit Startwert (RND), Textfunktionen (LEN, MID$, ASC, CHR$), die Anzeige (CLS, LOCATE, CURSOR), die Tastatur (KEY) und die LED. Dazu Schleifen, Bedingungen und Variablen aus Kapitel 3. Wenn Sie das Programm verstanden haben, können Sie eigene Spiele schreiben.
