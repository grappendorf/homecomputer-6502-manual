Bisher haben Sie dem Computer einzelne Befehle gegeben, und er hat sie sofort ausgeführt. In diesem Kapitel schreiben Sie Ihre ersten Programme. Ein Programm ist eine Liste von Befehlen, die sich der Computer merkt und dann der Reihe nach abarbeitet, so oft Sie wollen.

Die Sprache dafür heißt BASIC. Der HomeComputer 6502 hat Microsoft BASIC in der Version 1.1 fest eingebaut. Es ist sofort nach dem Einschalten bereit.

Das erste Programm

Tippen Sie die folgenden zwei Zeilen ein und drücken Sie nach jeder Zeile Enter:

10 PRINT "HALLO"
20 GOTO 10

Diesmal passiert nach Enter nichts. Das ist richtig so. Weil die Zeilen mit einer Zahl beginnen, führt der Computer sie nicht aus, sondern speichert sie. Die Zahl am Anfang ist die Zeilennummer. Sie legt fest, in welcher Reihenfolge die Zeilen im Programm stehen. Erlaubt sind Nummern von 0 bis 63999.

Jetzt starten Sie das Programm mit dem Befehl RUN:

RUN

Zeile 10 schreibt HALLO auf die Anzeige. Zeile 20 sagt: „Mach bei Zeile 10 weiter.“ Der Computer springt zurück, schreibt wieder HALLO, springt wieder zurück, und so weiter, ohne Ende. So etwas nennt man eine Endlosschleife.

Ein Programm anhalten

Drücken Sie Pause oder Strg + C. Das Programm hält an, und der Computer meldet, in welcher Zeile er gerade war:

Mit CONT (für englisch continue, weitermachen) läuft das Programm an derselben Stelle weiter. Mit RUN beginnt es wieder von vorn.

Hinweis

Wenn ein Programm zu Ende ist oder angehalten wurde, schreibt der Computer keine Meldung wie READY. Der Cursor steht einfach in der nächsten Zeile, und Sie können weitertippen.

Groß oder klein?

Die Tastatur schreibt kleine Buchstaben. Große bekommen Sie, solange Sie Shift gedrückt halten. Für längere Texte drücken Sie einmal kurz Caps Lock: Dann kommen alle Buchstaben groß, bis Sie Caps Lock noch einmal drücken. Halten Sie bei eingeschaltetem Caps Lock die Shift-Taste, kommt ein kleiner Buchstabe. Nach dem Einschalten ist Caps Lock immer aus.

Für BASIC ist das kein Problem. Befehle und Variablennamen dürfen Sie klein tippen. Beim Speichern macht der Computer Großbuchstaben daraus, und so zeigt LIST sie auch. Nur Text zwischen Anführungszeichen bleibt genau so, wie Sie ihn getippt haben. Aus print "Hallo" wird im Programm PRINT "Hallo".

Die Listings in diesem Handbuch stehen so da, wie LIST sie zeigt: Befehle groß, Texte meist auch groß. Solche Texte tippen Sie mit gedrückter Shift-Taste oder mit Caps Lock, oder Sie schreiben sie klein, ganz wie Sie mögen. In den LCD-Kästen steht Ihre Eingabe klein, so wie sie auf der Anzeige erscheint.

Statt PRINT können Sie auch kurz ? schreiben.

Programme ansehen und ändern

Der Befehl LIST zeigt das Programm, das gerade im Speicher steht:

LIST
10 PRINT "HALLO"
20 GOTO 10

Bei längeren Programmen können Sie auch nur einen Teil ansehen:

Eingabezeigt
LISTdas ganze Programm
LIST 30nur Zeile 30
LIST 30-ab Zeile 30 bis zum Ende
LIST -30vom Anfang bis Zeile 30
LIST 100-200die Zeilen 100 bis 200

Die Anzeige hat nur vier Zeilen. Ist das Programm länger, hält LIST nach drei Zeilen an und schreibt MORE - PRESS A KEY. Die LED oben rechts leuchtet. Mit einer beliebigen Taste geht es weiter. Mit Pause oder Strg + C brechen Sie ab.

Zeilen ersetzen, löschen und einfügen

  • Ersetzen: Tippen Sie eine Zeile mit derselben Nummer neu ein. Die alte Zeile wird überschrieben.
  • Löschen: Tippen Sie nur die Zeilennummer und drücken Sie Enter.
  • Einfügen: Nehmen Sie eine Nummer, die zwischen zwei vorhandenen liegt. Aus 15 PRINT "WELT" wird eine neue Zeile zwischen 10 und 20.

Darum nummeriert man Programme in Zehnerschritten: 10, 20, 30. So bleibt Platz für Zeilen, die Ihnen später noch einfallen.

Eine Zeile zurückholen

Sie müssen eine Zeile nicht ganz neu tippen, um sie zu ändern. Drücken Sie in einer leeren Eingabezeile ↑. Der Computer holt die letzte Programmzeile auf die Anzeige. Jedes weitere ↑ holt die Zeile davor, ↓ die Zeile danach. Tippen Sie erst eine Zeilennummer und dann ↑, holt er genau diese Zeile.

Mit ← und → bewegen Sie den Cursor in der Zeile. Die Rücktaste löscht das Zeichen vor dem Cursor, Entf das Zeichen unter dem Cursor. Pos1 und Ende springen an den Anfang und ans Ende. Esc verwirft die ganze Zeile. Mit Enter übernehmen Sie die geänderte Zeile. Ändern Sie dabei die Zeilennummer, entsteht eine Kopie unter der neuen Nummer. Die alte Zeile bleibt stehen.

Eine Zeile darf bis zu 120 Zeichen lang sein. Auf der Anzeige läuft sie nach 40 Zeichen in der nächsten Zeile weiter.

Neu anfangen

NEW löscht das ganze Programm und alle Variablen. Es gibt keine Sicherheitsabfrage. Wie Sie ein Programm vorher auf Diskette speichern, steht in Kapitel 6.

Mehrere Befehle in einer Zeile

In eine Zeile passen mehrere Befehle, getrennt durch einen Doppelpunkt. Mit REM (für englisch remark, Bemerkung) schreiben Sie einen Kommentar. Alles hinter REM ignoriert der Computer, auch ein Doppelpunkt.

10 REM MEIN ZWEITES PROGRAMM
20 PRINT "HALLO":PRINT "WELT"

Variablen

Eine Variable ist ein Name, unter dem sich der Computer einen Wert merkt. Sie geben ihr mit dem Gleichheitszeichen einen Wert:

10 A=5
20 B=A*2
30 PRINT A;B

Das Gleichheitszeichen bedeutet hier nicht „ist gleich“, sondern „bekommt den Wert“. Darum ist auch A=A+1 sinnvoll: A bekommt den alten Wert von A plus eins. Früher schrieb man dafür LET A=A+1. Das geht immer noch, das LET dürfen Sie aber weglassen.

Drei Arten von Variablen

BeispielenthältBereich
A, X1, ZZZahl mit Kommaetwa 9 gültige Stellen
A%, N%ganze Zahl−32768 bis 32767

Text steht immer zwischen Anführungszeichen: N$="OTTO". Zwei Texte hängen Sie mit + aneinander: PRINT "HAUS"+"TIER" schreibt HAUSTIER. Geben Sie einer ganzen Zahl einen Wert mit Komma, fällt alles hinter dem Komma weg: Nach A%=7.9 ist A% gleich 7.

Eine Variable, der Sie noch nichts zugewiesen haben, ist 0 oder leer. RUN und NEW setzen alle Variablen wieder auf 0 oder leer.

Gute Namen

Ein Name beginnt mit einem Buchstaben. Danach dürfen Buchstaben und Ziffern folgen. Der Computer unterscheidet Namen aber nur an den ersten zwei Zeichen. NAME$ und NACHT$ sind für ihn dieselbe Variable NA$:

NAME$="OTTO":NACHT$="X":PRINT NAME$
X

Außerdem darf in einem Namen kein BASIC-Befehl stecken. TOTAL enthält TO, FORM enthält FOR. Beides führt zu ?SYNTAX ERROR. Am sichersten sind kurze Namen aus ein oder zwei Zeichen.

Ausgaben mit PRINT

PRINT kann mehrere Dinge auf einmal ausgeben. Was dazwischen steht, bestimmt den Abstand:

  • Ein Semikolon ; schreibt direkt dahinter weiter.
  • Ein Komma , springt in die nächste Spalte. Die Spalten sind 10 Zeichen breit.
  • Steht am Ende ein ; oder ,, bleibt der Cursor in der Zeile. Das nächste PRINT schreibt dort weiter.

Vor jede Zahl setzt PRINT ein Leerzeichen, bei negativen Zahlen steht dort das Minus. Hinter jede Zahl kommt ebenfalls ein Leerzeichen. Darum stehen Zahlen nie direkt aneinander.

Schleifen mit FOR … NEXT

Mit GOTO haben Sie schon eine Schleife gebaut, allerdings eine ohne Ende. Soll etwas genau fünfmal passieren, nehmen Sie FOR und NEXT:

10 FOR I=1 TO 5
20 PRINT I;
30 NEXT I
40 PRINT "FERTIG"

FOR setzt die Variable I auf 1. Alles bis NEXT wird ausgeführt. NEXT I erhöht I um eins und springt zurück, solange I nicht größer als 5 ist. Danach geht es mit der Zeile hinter NEXT weiter.

Andere Schritte

Mit STEP legen Sie fest, um wie viel die Variable jedes Mal wächst. Ein negativer Schritt zählt rückwärts:

FOR I=0 TO 20 STEP 5:PRINT I;:NEXT
 0  5  10  15  20
FOR I=10 TO 0 STEP -5:PRINT I;:NEXT
 10  5  0

Wie Sie sehen, darf hinter NEXT der Name auch fehlen. Dann gehört NEXT zur zuletzt begonnenen Schleife.

Hinweis

Eine FOR-Schleife läuft immer mindestens einmal. FOR I=5 TO 1 führt den Inhalt einmal mit I=5 aus, obwohl 5 schon größer als 1 ist.

Schleifen in Schleifen

Schleifen lassen sich ineinander schachteln. Die innere Schleife muss dabei vor der äußeren enden:

10 FOR I=1 TO 3
20 FOR J=1 TO 3
30 PRINT I*J;
40 NEXT J
50 PRINT
60 NEXT I

Das PRINT ohne alles in Zeile 50 beendet nur die Zeile auf der Anzeige.

Eingaben mit INPUT

Bisher stand alles schon im Programm. Mit INPUT fragt das Programm Sie, während es läuft:

10 INPUT "WIE HEISST DU";N$
20 PRINT "HALLO ";N$

INPUT schreibt den Text zwischen den Anführungszeichen, hängt ein Fragezeichen an und wartet. Was Sie tippen, landet nach Enter in der Variablen. Der Text und das Semikolon dürfen fehlen. Dann erscheint nur das Fragezeichen.

Ein INPUT kann auch mehrere Werte auf einmal abfragen. Trennen Sie sie beim Eintippen mit einem Komma. Geben Sie zu wenige ein, fragt der Computer mit ?? nach dem Rest:

10 INPUT "ZWEI ZAHLEN";A,B
20 PRINT "SUMME:";A+B

Erwartet das Programm eine Zahl und Sie tippen Buchstaben, antwortet der Computer mit ?REDO FROM START und fragt noch einmal. Das Programm läuft danach normal weiter.

Hinweis

INPUT geht nur in einem Programm. Direkt eingetippt meldet der Computer ?ILLEGAL DIRECT ERROR.

Entscheidungen mit IF … THEN

Ein Programm wird erst richtig nützlich, wenn es auf Eingaben reagiert. Dafür gibt es IF (wenn) und THEN (dann):

10 INPUT "WIE ALT BIST DU";A
20 IF A<18 THEN PRINT "NOCH NICHT VOLLJAEHRIG"
30 IF A>=18 THEN PRINT "VOLLJAEHRIG"

Ist die Bedingung hinter IF wahr, führt der Computer aus, was hinter THEN steht. Ist sie falsch, überspringt er den ganzen Rest der Zeile, auch alles hinter einem Doppelpunkt. Das können Sie nutzen:

20 IF A<18 THEN PRINT "ZU JUNG":GOTO 10

Hier springt das Programm nur dann zurück zu Zeile 10, wenn A kleiner als 18 ist.

Vergleiche

ZeichenbedeutetBeispiel

Texte lassen sich genauso vergleichen: IF A$="J" THEN …. Bei < und > gilt die Reihenfolge im Alphabet, "ABC" ist kleiner als "ABD".

Mehrere Bedingungen verbinden Sie mit AND (beide müssen stimmen) und OR (eine muss stimmen). NOT dreht eine Bedingung um:

IF X>1 AND X<5 THEN PRINT "DAZWISCHEN"

THEN mit Zeilennummer

Steht hinter THEN nur eine Zeilennummer, springt der Computer dorthin. IF A=0 THEN 100 ist dasselbe wie IF A=0 THEN GOTO 100 oder IF A=0 GOTO 100.

Für Neugierige

Ein Vergleich ist für den Computer eine Rechnung. Wahr ergibt −1, falsch ergibt 0. Probieren Sie PRINT 5>3, 3>5. IF prüft nur, ob der Wert 0 ist. Darum führt IF 7 THEN … den Befehl aus und IF 0 THEN … nicht.

Ein Ratespiel

Jetzt haben Sie alles zusammen für ein richtiges Spiel. Der Computer denkt sich eine Zahl zwischen 1 und 100, und Sie raten:

10 REM RATESPIEL
20 Z=INT(RND(1)*100)+1
30 V=0
40 PRINT "ICH DENKE MIR EINE ZAHL VON 1 BIS 100."
50 INPUT "DEIN TIPP";T
60 V=V+1
70 IF T<Z THEN PRINT "ZU KLEIN.":GOTO 50
80 IF T>Z THEN PRINT "ZU GROSS.":GOTO 50
90 PRINT "RICHTIG! DU HAST";V;"VERSUCHE GEBRAUCHT."
100 INPUT "NOCH EINMAL (J/N)";A$
110 IF A$="J" OR A$="j" THEN 20
120 END

Sie finden das Programm auch im Firmware-Projekt als examples/ratespiel.bas. Ist das Laufwerk aus Kapitel 6 verbunden, laden Sie es mit LOAD "ratespiel".

So arbeitet das Programm:

  • Zeile 20 erzeugt die geheime Zahl Z. RND(1) liefert eine Zufallszahl zwischen 0 und 1. Mal 100 genommen und mit INT auf eine ganze Zahl abgerundet, ergibt das 0 bis 99. Plus eins: 1 bis 100.
  • Zeile 30 setzt den Zähler für die Versuche auf 0.
  • Zeilen 50 und 60 fragen nach Ihrem Tipp und zählen mit.
  • Zeilen 70 und 80 vergleichen den Tipp mit Z. Liegt er daneben, gibt es einen Hinweis, und das Programm fragt in Zeile 50 erneut.
  • Zeile 90 wird nur erreicht, wenn der Tipp weder zu klein noch zu groß war.
  • Zeilen 100 und 110 starten auf Wunsch eine neue Runde. Weil die Tastatur klein schreibt, prüft Zeile 110 auf "J" und auf "j". END beendet das Programm.

Die Umlaute sind im Programm als AE, OE und UE geschrieben. So sieht der Text auf jeder Anzeige und jedem Terminal gleich aus.

Hinweis

Nach dem Einschalten liefert RND(1) immer dieselbe Folge von Zufallszahlen. Die erste Runde beginnt deshalb jedes Mal mit derselben Zahl. Wie Sie das ändern, zeigt Kapitel 4.

Fehlermeldungen

Versteht der Computer etwas nicht, meldet er einen Fehler. Die Meldung beginnt mit einem Fragezeichen. Passiert der Fehler in einem Programm, steht dahinter die Zeilennummer:

10 PRINT "A"
20 PRUNT "B"

Keine Sorge: Ein Fehler kann dem Computer nicht schaden. Holen Sie die Zeile mit ↑ zurück, verbessern Sie sie und starten Sie das Programm neu. Die Meldungen, die Ihnen in diesem Kapitel am ehesten begegnen:
