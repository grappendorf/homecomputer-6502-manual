Nach der Anzeige braucht der Computer eine Eingabe. Eine Notebook-Tastatur ist dafür ideal: Sie ist flach, hat über 80 Tasten und besteht nur aus einer Schaltmatrix. Dafür kommt ein zweites VIA dazu.

Die Tastaturmatrix

Eine Tastatur mit 80 Tasten hätte 80 Leitungen, wenn jede Taste ihren eigenen Anschluss bekäme. Stattdessen sind die Tasten in einem Gitter angeordnet. Jede Taste verbindet eine Zeilenleitung mit einer Spaltenleitung. Bei einer Matrix aus 14 Zeilen und 8 Spalten kommt man mit 22 Leitungen für 112 Tasten aus.

Gelesen wird so: Die Zeilen sind Ausgänge, die Spalten Eingänge. Der Computer legt genau eine Zeile auf Low und liest alle Spalten. Die Eingänge haben einen Pull-up-Widerstand und lesen darum 1, solange keine Taste sie nach unten zieht. Ist in der gewählten Zeile eine Taste gedrückt, liest die zugehörige Spalte eine 0. Zeile für Zeile entsteht so ein Bild aller Tasten.

Aus Zeile und Spalte wird ein Scancode: Zeile × 8 + Spalte. Er läuft von 0 bis 111. Der Wert $FF bedeutet „keine Taste“.

Zwei Dinge sind zu beachten. Mechanische Kontakte prellen: Beim Drücken schalten sie einige Millisekunden lang hin und her. Das Programm tastet darum zweimal im Abstand von 10 ms ab und glaubt nur, was zweimal gleich ist. Und ohne Dioden an den Tasten können mehrere gleichzeitig gedrückte Tasten „Geistertasten“ erzeugen. Unser Programm meldet deshalb immer nur eine Taste.

Eigene Tastatur

Eine andere Tastatur hat eine andere Matrix. Messen Sie sie aus: Legen Sie die Anschlusspads der Folie frei und halten Sie eine Prüfspitze eines Durchgangsprüfers an ein Pad. Mit der anderen Spitze berühren Sie die übrigen Pads, während Sie nacheinander alle Tasten drücken. Der Prüfer piept, wenn eine Taste die beiden Pads verbindet. Notieren Sie für jede Taste das Padpaar. Die Pads fallen so in zwei Gruppen, die Zeilen und die Spalten.

Die Schaltung

Ein zweites VIA (IC11) bekommt den Ausgang Y2 des Dekoders als Chip-Select. Es liegt damit bei $7F40 bis $7F5F: Port B bei $7F40, Port A bei $7F41, die Richtungsregister bei $7F42 und $7F43.

  • Spalten: Port A des zweiten VIA, PA0 bis PA7, als Eingänge. Der 6522 hat an Port A eigene Pull-up-Widerstände, sie brauchen keine externen.
  • Zeilen 0 bis 7: Port B des zweiten VIA, PB0 bis PB7, als Ausgänge.
  • Zeilen 8 bis 13: PB0 bis PB5 des ersten VIA. Das ist der Grund, weshalb die LED im Kapitel 9 von PB0 nach PA7 umgezogen ist. PB6 und PB7 bleiben frei.

Die Tastatur ist über 22 Drähte an die Stiftleiste JP3 angeschlossen. In den Zeichnungen heißen die Zeilen R0 bis R13 (Row) und die Spalten C0 bis C7 (Column):

Aufbau

Zuerst bekommt der Dekoder seinen zweiten Ausgang:

  1. Schalten Sie die Spannung aus. Führen Sie Y2 (Pin 13 von IC10, Loch 8j) als /CS_VIA2 heraus.

Dann das zweite VIA:

  1. Führen Sie +5 V und GND zu einem neuen Steckbrett und verbinden Sie dort die oberen Schienen mit den unteren.
  2. Stecken Sie IC11 über die Rinne, Kerbe links, Pin 1 in Loch 4d (breites IC, Reihen d und h).
  3. Versorgung wie beim ersten VIA: Pin 20 (Loch 23a) an +5 V, Pin 1 (4a) an GND, CS1 (Pin 24, Loch 20j) an +5 V. C15 zwischen die oberen Schienen. /IRQ (Pin 21) bleibt offen.

Die Zeilen 8 bis 13 liegen am ersten VIA. Dort bekommen die Pins 10 bis 15 (PB0 bis PB5, Löcher 13a bis 18a) je einen Draht R8 bis R13:

Schließlich die Tastatur:

  1. Löten Sie 22 Drähte an die Anschlusspads der Tastaturfolie, in der Reihenfolge aus der Tabelle der Matrix.
  2. Stecken Sie die Stiftleiste JP3 in die Löcher 5c bis 26c und führen Sie die Drähte in die Löcher 5d bis 26d. Pin 1 ist links.
  3. Verbinden Sie R0 bis R7 und C0 bis C7 mit dem zweiten VIA und R8 bis R13 mit dem ersten VIA, jeweils mit dem Draht gleichen Namens.

Das Programm

Das Programm meldet jede neu gedrückte Taste mit ihrem Scancode über die serielle Schnittstelle. Es tastet in keys_scan die 14 Zeilen nacheinander ab. keys_update wiederholt die Abtastung nach 10 ms und merkt sich den Code nur, wenn beide Ergebnisse übereinstimmen.

Wichtig: Die Zeilen 8 bis 13 liegen an Port B des ersten VIA, dessen PB6 und PB7 anderweitig benutzt werden können. Das Programm ändert deshalb nur die unteren sechs Bits, mit einer Maske. Hauptprogramm:

        .setcpu "6502"

ACIA_DATA    = $7f00
ACIA_STATUS  = $7f01
ACIA_COMMAND = $7f02
ACIA_CONTROL = $7f03
VIA1_ORB     = $7f20
VIA1_DDRB    = $7f22
VIA2_ORB     = $7f40
VIA2_IRA     = $7f41
VIA2_DDRB    = $7f42
VIA2_DDRA    = $7f43

        .zeropage
ptr:    .res 2
tmp:    .res 1
code:   .res 1                  ; Code der gedrückten Taste ($FF = keine)
last:   .res 1                  ; zuletzt gemeldeter Code

        .segment "VECTORS"
        .word   nmi
        .word   reset
        .word   irq

        .code
reset:  jmp main
nmi:    rti
irq:    rti

main:   cld
        ldx #$ff
        txs
        jsr acia_init
        jsr keys_init
        lda #$ff
        sta last
loop:   jsr keys_update
        lda code
        cmp last                ; nur Änderungen melden
        beq loop
        sta last
        cmp #$ff
        beq loop                ; Loslassen wird nicht gemeldet
        lda #<;msg_key
        ldx #>;msg_key
        jsr puts
        lda code
        jsr puthex
        jsr newline
        jmp loop

Die Abtastung der Tastatur:

; Ports einstellen: Zeilen Ausgang, Spalten Eingang
keys_init:
        lda #$ff
        sta VIA2_DDRB           ; VIA2 Port B: Zeilen 0 bis 7 als Ausgang
        lda #$00
        sta VIA2_DDRA           ; VIA2 Port A: Spalten 0 bis 7 als Eingang
        lda VIA1_DDRB
        ora #$3f                ; VIA1 PB0 bis PB5: Zeilen 8 bis 13 als Ausgang
        sta VIA1_DDRB
        jmp rows_idle

; alle Zeilen auf High
rows_idle:
        lda #$ff
        sta VIA2_ORB
        lda VIA1_ORB
        ora #$3f
        sta VIA1_ORB
        rts

; X = Zeile (0 bis 13): nur diese Zeile auf Low
select_row:
        jsr rows_idle
        cpx #8
        bcs @via1
        lda row_mask,x
        sta VIA2_ORB
        rts
@via1:  lda row_mask - 8,x
        and VIA1_ORB
        sta VIA1_ORB
        rts

row_mask: .byte $fe, $fd, $fb, $f7, $ef, $df, $bf, $7f

; Tastatur abtasten: A = Scancode oder $FF
keys_scan:
        ldx #0
@row:   jsr select_row
        lda VIA2_IRA
        eor #$ff                ; gedrückt = Bit gesetzt
        bne @found
        inx
        cpx #14
        bne @row
        jsr rows_idle
        lda #$ff
        rts
@found: ldy #0
@bit:   lsr
        bcs @done
        iny
        bne @bit
@done:  sty tmp                 ; Y = Spalte
        txa
        asl
        asl
        asl
        ora tmp                 ; Zeile * 8 + Spalte
        pha
        jsr rows_idle
        pla
        rts

; Abtasten mit Entprellen: Code in code
keys_update:
        jsr keys_scan
        cmp #$ff
        beq @none
        sta code
        ldx #10                 ; 10 ms warten und noch einmal abtasten
        jsr delay_ms
        jsr keys_scan
        cmp code
        beq @done
@none:  lda #$ff
        sta code
@done:  rts

delay_ms:
@ms:    ldy #199
@us:    dey
        bne @us
        dex
        bne @ms
        rts

Die Routinen zur Ausgabe über die ACIA (putc, puts, puthex und newline) kennen Sie aus Kapitel 7. Das vollständige Programm steht in programme/de/tastatur.s.

Hinweis

Meldet sich keine Taste, dann prüfen Sie zuerst, ob das zweite VIA unter $7F40 antwortet (mit dem Monitor: w 7f42 ff und danach m 7f40). Meldet eine Taste den falschen Scancode, sind zwei Drähte vertauscht. Die Tabelle der Matrix zeigt, welcher.
